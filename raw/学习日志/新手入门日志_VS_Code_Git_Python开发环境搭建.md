## 1. 场景还原：我遇到了什么问题

### 问题一：VS Code 里弹出一个看不懂的页面

**截图内容**：VS Code 的 Python 扩展欢迎页面，上面有 5 个步骤。

**我当时不懂的**：这个页面是干嘛的？要我去哪里找？

**答案**：这是 Python 扩展的「入门向导」，它在手把手引导你做四件事：
1. 打开一个项目文件夹
2. 创建一个 `.py` 文件
3. 选一个 Python 解释器（就是让电脑知道用哪个 Python 来运行代码）
4. 运行和调试代码

**通俗理解**：就像一个游戏的新手教程，告诉你先做什么、再做什么。

---

### 问题二：GitLens 提示 "No repository detected"

**截图内容**：GitLens 扩展面板显示没有检测到仓库。

**我当时不懂的**：这是什么意思？

**答案**：GitLens 是 VS Code 里的一个 Git 增强工具，它能让你看到代码是谁写的、什么时候改的、改了什么。但它需要一个「Git 仓库」才能工作。

你当前打开的文件夹还没有被 Git 管理，所以它报了这个提示。

**通俗理解**：GitLens 就像一个图书管理员，但你现在还没有图书馆（Git 仓库），所以它没法工作。

---

### 问题三：源代码管理面板显示「打开文件夹」和「克隆仓库」

**我当时不懂的**：去哪里找？两个按钮分别是什么意思？

**答案**：
- **打开文件夹**：你电脑上已经有一个用 Git 管理的项目，直接打开就行
- **克隆仓库**：从网上（GitHub / GitLab / Gitee）下载别人的项目到本地

**通俗理解**：
- 「打开文件夹」= 你去你已经建好的图书馆
- 「克隆仓库」= 你从网上复制一整个图书馆到你的电脑

---

### 问题四：怎么创建 Git 仓库、配置用户名

**操作过程**：
1. 在当前文件夹运行 `git init` — 初始化了一个空的 Git 仓库
2. 提交时报错：`Author identity unknown` — Git 不知道你是谁
3. 配置了全局用户名和邮箱：
   ```
   git config --global user.name "Jerry"
   git config --global user.email "806759480@qq.com"
   ```

**通俗理解**：
- `git init` = 在当前文件夹建立一个「档案室」
- 用户名和邮箱 = 你在这个档案室里的「签名」，每次修改都会盖上你的章，别人就知道是谁改的

---

### 问题五：把项目放到 D 盘，起个好名字

**操作**：
- 在 D 盘创建了 `D:\CodeProjects` 文件夹
- 在里面初始化了 Git 仓库
- 以后所有代码项目都可以往这个文件夹里放

**为什么放 D 盘**：C 盘是系统盘，放太多文件会影响电脑速度，D 盘专门放代码项目更好管理。

## 2. 核心知识一：VS Code 是什么，为什么用它

### 一句话解释

VS Code（全称 Visual Studio Code）是微软出的一款**免费代码编辑器**，是目前全世界最流行的写代码工具。

### 它和记事本有什么区别？

| | 记事本 | VS Code |
|---|---|---|
| 写代码 | 能写，但全是黑白的 | 自动高亮关键词，一目了然 |
| 找错误 | 全靠眼睛看 | 自动标红报错，告诉你在第几行 |
| 运行代码 | 不行 | 一键运行 |
| 装插件 | 不行 | 有插件市场，想加什么功能装什么 |
| Git 管理 | 不行 | 内置支持，改了什么一目了然 |

### 核心概念：扩展（Extension）

VS Code 本身只是一个「壳」，它的强大之处在于可以装各种**扩展**，就像手机装 App 一样。

今天涉及到的扩展：
- **Python 扩展**：让你能在 VS Code 里写 Python、运行 Python、调试 Python
- **GitLens**：增强 Git 功能，让你看到每行代码是谁写的、什么时候改的

### 安装 VS Code（如果还没装）

1. 去官网 https://code.visualstudio.com/ 下载
2. 双击安装，一路「下一步」就行
3. 打开后，左侧有一排图标，这叫「活动栏」

### VS Code 活动栏图标速查

| 图标 | 名称 | 干什么的 |
|---|---|---|
| 📄 文件 | 资源管理器 | 看文件夹里有哪些文件 |
| 🔍 搜索 | 搜索 | 在项目里搜关键词 |
| 🌿 分支 | 源代码管理 | Git 相关操作（提交、推送等） |
| ▶️ 播放 | 运行和调试 | 运行代码、打断点 |
| 🧩 方块 | 扩展 | 装插件的地方 |

## 3. 核心知识二：Git 是什么，为什么需要它

### 一句话解释

Git 是**版本控制系统**，说白了就是代码的「存档 + 时光机」。

### 没有 Git 的时候，你是怎么存文件的？

```
论文.docx
论文_修改版.docx
论文_最终版.docx
论文_最终版2.docx
论文_真的最终版.docx
论文_打死不改版.docx
```

这就是 Git 要解决的问题。

### Git 能做什么？

1. **记录每一次修改**：什么时候改了、改了哪里、为什么改
2. **回退到任意版本**：改坏了？一键回到昨天的版本
3. **多人协作**：你和同事同时改一个文件，Git 能智能合并，不会互相覆盖
4. **分支管理**：想试新功能但怕搞坏？开一个「分支」，搞坏了不影响主线

### 核心概念图解

```
工作目录（你的文件夹）
    │
    │  git add（暂存）
    ↓
暂存区（准备提交的修改）
    │
    │  git commit（提交）
    ↓
本地仓库（.git 文件夹，存所有历史版本）
    │
    │  git push（推送）
    ↓
远程仓库（GitHub / GitLab / Gitee 上的备份）
```

### Git 三板斧（你最常用的三个命令）

```bash
# 1. 把修改加入暂存区（准备提交）
git add .

# 2. 提交修改（正式存档）
git commit -m "我做了什么修改"

# 3. 推送到远程仓库（备份到网上）
git push
```

### GitHub / GitLab / Gitee 是什么？

它们都是**托管 Git 仓库的网站**，你可以理解为「代码的百度网盘」：
- **GitHub**：全球最大，国外用得多
- **Gitee（码云）**：国内版，速度快
- **GitLab**：企业用得多

## 4. 核心知识三：Python 开发环境是什么意思

### 什么是「开发环境」？

就像你要做饭，需要：
- **厨房**（操作系统：Windows）
- **锅和灶**（编程语言：Python）
- **菜刀和案板**（代码编辑器：VS Code）
- **调料**（第三方库：别人写好的工具包）

这些加在一起，就是你的「开发环境」。

### Python 解释器是什么？

Python 代码本身只是文本，电脑不认识。需要一个「翻译官」把 Python 代码翻译成电脑能懂的语言，这个翻译官就叫**Python 解释器**。

你电脑上可能装了多个 Python 版本（比如 Python 3.10、3.12），VS Code 需要你告诉它用哪一个。

### 虚拟环境（venv）是什么？

每个 Python 项目可能需要不同版本的第三方库。比如：
- 项目 A 需要 `requests` 库的 2.0 版本
- 项目 B 需要 `requests` 库的 3.0 版本

如果都装在全局，就会打架。所以每个项目建一个「虚拟环境」，库装在自己的环境里，互不影响。

**通俗理解**：就像每个项目有自己的「工具箱」，不会和别的项目混在一起。

## 5. 实战操作：完整的搭建步骤

### 第一步：安装 Python

1. 去 https://www.python.org/downloads/ 下载（推荐 3.11 或 3.12）
2. 安装时**一定要勾选**「Add Python to PATH」
3. 装完后，按 `Win + R`，输入 `cmd` 回车，输入 `python --version` 验证

### 第二步：安装 VS Code

1. 下载安装：https://code.visualstudio.com/
2. 打开后，点左侧「扩展」图标，搜索并安装：
   - **Python**（微软官方）
   - **GitLens**（Git 增强工具）
   - **Chinese**（中文语言包，可选）

### 第三步：安装 Git

1. 去 https://git-scm.com/downloads 下载 Windows 版
2. 一路「下一步」，默认选项就可以
3. 装完后，打开 CMD，输入 `git --version` 验证

### 第四步：配置 Git 身份

打开 CMD（或 VS Code 里的终端），输入：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@qq.com"
```

这一步只需要做一次。

### 第五步：创建你的第一个项目

1. 在 D 盘创建文件夹 `D:\CodeProjects`
2. 打开 VS Code → 文件 → 打开文件夹 → 选 `D:\CodeProjects`
3. 按 `Ctrl + `` ` 打开终端，输入：
   ```bash
   git init
   ```
4. 创建一个 `.py` 文件试试：
   ```python
   print("Hello, 世界！")
   ```
5. 右键 → 「在终端中运行 Python 文件」

### 第六步：第一次 Git 提交

```bash
git add .
git commit -m "我的第一个项目"
```

## 6. 拓展学习：从入门到能干活

### 6.1 学会用终端（命令行）

你可能一直用鼠标点来点去，但在编程世界里，**终端（命令行）** 是更高效的操作方式。

**VS Code 打开终端**：`Ctrl + `` `（Tab 上面那个键）

**必学的 10 个终端命令**：

| 命令 | 作用 | 示例 |
|---|---|---|
| `cd 文件夹名` | 进入文件夹 | `cd D:\CodeProjects` |
| `cd ..` | 返回上一级 | `cd ..` |
| `dir` | 看当前目录有什么 | `dir` |
| `mkdir 名字` | 创建文件夹 | `mkdir my_project` |
| `type nul > 文件名` | 创建空文件 | `type nul > hello.py` |
| `cls` | 清屏 | `cls` |
| `python 文件名.py` | 运行 Python | `python hello.py` |
| `pip install 库名` | 安装 Python 库 | `pip install requests` |
| `code .` | 用 VS Code 打开当前文件夹 | `code .` |
| `exit` | 关闭终端 | `exit` |

### 6.2 理解 Python 虚拟环境（重要！）

这是新手最容易踩的坑，所以单独讲。

**创建虚拟环境**：
```bash
# 在项目文件夹里
python -m venv venv
```

这会在项目里创建一个 `venv` 文件夹，里面有一份独立的 Python。

**激活虚拟环境**：
```bash
# Windows
venv\Scripts\activate

# 激活后，终端前面会多一个 (venv) 标识
```

**退出虚拟环境**：
```bash
deactivate
```

**什么时候用虚拟环境？**
- 每开一个新项目，就创建一个新的虚拟环境
- 永远不要在全局环境里装各种库

### 6.3 Git 进阶：理解分支（Branch）

分支是 Git 最强大的功能之一。

**什么是分支？**

想象你在写一本书：
- **主分支（main/master）**：已经出版的书，稳定版本
- **功能分支（feature-xxx）**：你在尝试写新章节，写坏了不影响已出版的书

**实战操作**：

```bash
# 创建并切换到新分支
git checkout -b feature-login

# 在这个分支里随便改，不会影响主分支
# ...写代码...

# 改完了，合并回主分支
git checkout main          # 切回主分支
git merge feature-login    # 合并
git branch -d feature-login  # 删除功能分支
```

### 6.4 GitHub 远程仓库入门

**为什么需要远程仓库？**
- 备份：电脑坏了代码不丢
- 协作：和别人一起写代码
- 展示：面试时给面试官看

**操作流程**：

1. 去 https://github.com 注册账号
2. 点右上角 `+` → `New repository`
3. 起个名字，点 `Create repository`
4. 把你的本地代码推上去：
   ```bash
   git remote add origin https://github.com/你的用户名/仓库名.git
   git branch -M main
   git push -u origin main
   ```

**国内替代**：如果用 GitHub 太慢，可以用 https://gitee.com（码云），操作基本一样。

### 6.5 Python 必学的 5 个基础概念

如果你刚开始学 Python，先把这 5 个搞清楚：

1. **变量**：给数据起个名字
   ```python
   name = "Jerry"
   age = 25
   ```

2. **数据类型**：数字、文字、真假的区别
   ```python
   num = 10        # 整数
   pi = 3.14       # 小数
   text = "你好"    # 字符串
   ok = True       # 布尔值
   ```

3. **条件判断**：根据不同情况做不同的事
   ```python
   if age >= 18:
       print("成年了")
   else:
       print("未成年")
   ```

4. **循环**：重复做一件事
   ```python
   for i in range(5):
       print(f"第 {i+1} 次")
   ```

5. **函数**：把一段代码打包，可以反复调用
   ```python
   def say_hello(name):
       print(f"你好, {name}!")

   say_hello("Jerry")
   ```

### 6.6 VS Code 提高效率的 5 个技巧

1. **`Ctrl + P`**：快速打开文件，不用在文件夹里翻
2. **`Ctrl + Shift + P`**：命令面板，所有操作都能搜到
3. **`Ctrl + /`**：快速注释/取消注释一行代码
4. **`Alt + ↑/↓`**：上下移动一行代码
5. **`Ctrl + D`**：选中相同的词，批量修改

### 6.7 .gitignore 文件：告诉 Git 忽略什么

有些文件不应该提交到 Git（比如虚拟环境文件夹、密码文件、临时文件）。

在项目根目录创建 `.gitignore` 文件：

```
# Python 虚拟环境
venv/

# Python 缓存
__pycache__/
*.pyc

# VS Code 配置
.vscode/

# 系统文件
.DS_Store
Thumbs.db
```

## 7. 学习方法论：计算机小白如何高效学习

### 费曼学习法（推荐）

核心理念：**能用简单的话教会别人，才算你真的懂了。**

具体做法：
1. 选一个你想学的概念（比如「Git 是什么」）
2. 假装讲给一个 10 岁小孩听，用最简单的话解释
3. 卡住了？回去重新学
4. 简化，用类比来理解（比如把 Git 比作「存档系统」「时光机」）

**今天这整篇文档，就是用费曼学习法写的。**

### 项目驱动学习

不要只看教程不写代码。每学一个新东西，立刻动手做一个项目：
- 学了变量和循环 → 做一个「猜数字」游戏
- 学了文件操作 → 做一个「日记本」程序
- 学了网络请求 → 做一个「天气查询」工具

### 遇到报错怎么办？

1. **先读报错信息**：Python 的错误提示其实很友好，它会告诉你是第几行出了什么问题
2. **复制报错去搜索**：99% 的报错别人都遇到过，Google / 百度一下
3. **问 AI**：把报错信息和你做了什么告诉 AI（比如 ChatGPT、Claude、或者我）
4. **记录**：每解决一个问题，记下来，下次遇到就不用再搜了

### 推荐学习路线（从零开始）

```
第 1 周：装上 VS Code + Python，写出第一行代码
第 2 周：学会变量、条件、循环、函数
第 3 周：学会列表、字典、文件读写
第 4 周：学会 pip 安装第三方库，做一个小项目
第 5 周：学会 Git 基本操作（add、commit、push）
第 6 周：在 GitHub 上发布你的第一个项目
```

## 8. 速查卡：常用命令和操作

### Git 命令

```bash
git init                          # 初始化仓库
git status                        # 查看当前状态
git add .                         # 暂存所有修改
git add 文件名                     # 暂存指定文件
git commit -m "说明"              # 提交
git log                           # 查看提交历史
git checkout -b 分支名             # 创建并切换分支
git branch                        # 查看所有分支
git merge 分支名                   # 合并分支
git remote add origin 地址         # 关联远程仓库
git push -u origin main          # 推送到远程
git pull                          # 从远程拉取最新代码
git clone 地址                    # 克隆远程仓库
```

### Python 虚拟环境命令

```bash
python -m venv venv               # 创建虚拟环境
venv\Scripts\activate             # 激活（Windows）
source venv/bin/activate          # 激活（Mac/Linux）
deactivate                        # 退出虚拟环境
pip install 库名                   # 安装包
pip list                          # 查看已安装的包
pip freeze > requirements.txt     # 导出依赖列表
pip install -r requirements.txt   # 从列表安装依赖
```

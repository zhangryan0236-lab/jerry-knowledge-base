# Subagent（子代理）

## 一句话定义

Subagent 是主 Agent 在运行时**按需动态创建**的临时 AI Agent，专门负责某一块子任务。用完即焚。

## 核心要点

1. **谁创建**：主 Agent（不是用户手动创建）
2. **生命周期**：临时——领任务 → 执行 → 返回结果 → 销毁
3. **独立上下文**：Subagent 看不到主 Agent 的完整对话历史
4. **有状态**：知道自己在执行什么任务

## 类比

- 主 Agent = **总经理**（拆解任务、调度指挥）
- Subagent = **部门经理**（领到具体任务，独立执行，返回结果）

## 什么时候用 / 不用

| 该用 | 不该用 |
|------|--------|
| 任务可以独立拆解，子任务之间依赖少 | 简单任务（改个文件名、查个字段） |
| 需要并行执行（同时查 5 份资料） | 严重依赖完整对话上下文 |
| 需要特定专业视角（安全、性能） | 上一步结果决定下一步方向 |

**判断原则**：启动 Subagent 有成本（上下文加载、通信开销）。收益大于成本时再用。

## Subagent vs Skill

| | Skill（技能） | Subagent（子代理） |
|--|-------------|-------------------|
| 本质 | 磁盘上的操作手册（`.md` 文件） | 内存中的 Agent 实例 |
| 创建者 | **你**（提前写好） | **主 Agent**（运行时自动创建） |
| 生命周期 | 永久存在 | 用完即焚 |
| 类比 | 一本《电工操作规程》 | 临时叫来的电工 |

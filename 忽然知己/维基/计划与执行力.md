# 计划与执行力

> 计划失败的根本原因不是"意志力不够"——是你的计划**违背了你的身体和心理的基本运作规律**。
>
> 综合自：[[../2025-05-31_008_如何制定学习计划（起步版）]]、[[../2025-06-01_009_如何优化学习计划（高阶版）]]、[[../2025-06-20_015_计划完不成怎么办]]、[[../2025-06-27_017_具体制定计划（实战版）]]、[[../2025-08-04_028_如何制定暑期计划]]、[[../2025-10-08_047_短期计划VS长期计划]]、[[../2026-01-09_075_四象限工作法]]、[[../2026-03-14_087_西蒙学习法]]、[[../2026-04-05_093_上班如何学习]]等。

## 一句话定义

一个好计划 = **足够的休息（身体信任你）** + **合理的工作量（客观可行）** + **可视化的进度（自我反馈）**。

---

## 一、计划失败的底层原因

来自 [[../2025-05-31_008_如何制定学习计划（起步版）]]：

> 制定计划的本质是**自我约束**——意识对身体和潜意识的强行控制。如果你的计划一开始就很严格，你的身体会自动造反。

### 身体造反的机制

```
意识：我要学12小时！
身体：不，你不想。
      ↓
身体造反：溜号、划水、注意力分散、拖延
      ↓
计划崩溃：连你自己都觉得遵从这个计划没有意义
```

### 核心原则

> **休息 > 工作**。只有在你的身体得到了足够多可以休息的反馈之后，它才会觉得能够全力投入工作。

---

## 二、清华学霸的计划模板

来自 [[../2025-05-31_008]] 和 [[../2025-06-27_017_具体制定计划（实战版）]]：

| 元素 | 具体做法 |
|------|---------|
| **工作时间** | 每天最多 7 小时高效学习（上午 2h + 下午 2h + 晚上 3h） |
| **休息间隔** | 每 1 小时工作 → 10 分钟透气（强制离开座位） |
| **意外处理** | 如工作时间内被意外打断 → 时间从休息时间里扣除 |
| **超时处理** | 进入心流超过工作时间 → **强制休息**（不让心流透支后面的精力） |
| **严格切换** | 工作时间绝不允许不工作；休息时间绝不允许想工作 |

### 关键：这两个小时的纯度

> "我既然坐下了，从这一分钟开始就是工作时间。我不考虑其他所有一切。"
>
> 这种纯度不是天赋，是**设计出来的**——因为你明确知道后面有休息，所以你可以在工作时间内 100% 投入。

### 效率证据

> 高中时期：数学卷子 45 分钟一套。历史选择题 5 秒一道。一本练习册发下来，两周肯定做完。
>
> 不是因为天赋——是因为**每一分钟的纯度都很高**。

来自 [[../2025-05-31_008]]：

> 只要能把计划坚持 5-7 天，它就会成为习惯。之后你不需要再考虑"我要遵循什么计划"——它会像呼吸一样自然。

## 四、短期计划 vs 长期计划

来自 [[../2025-10-08_047_短期计划VS长期计划]]：

| 维度 | 短期计划 | 长期计划 |
|------|---------|---------|
| **时间跨度** | 1天-1周 | 1月-1年 |
| **关注什么** | 具体任务（今天做什么题） | 方向和大目标 |
| **作用** | 提供每天的确定性和成就感 | 提供方向和意义感 |
| **失败原因** | 安排太满 | 不拆解为短期，永远在"未来" |

> 两者必须配合：长期计划给你方向，短期计划给你每天可执行的步骤。只有长期没有短期 = 空中楼阁。只有短期没有长期 = 无头苍蝇。

---

## 五、计划完不成的处理

来自 [[../2025-06-20_015_计划完不成怎么办]]：

> 计划完不成 ≠ 你不行。计划完不成 = 你需要调整计划。

**应对三步**：
1. 不要自责——自责让下一次计划更难执行（身体会记住"计划=痛苦"）
2. 分析原因——是高估了自己的能力？还是被意外打断？
3. 调整计划——把工作量砍掉 30%，下周再慢慢加回来

## 六、高阶工具

### 四象限工作法

来自 [[../2026-01-09_075_四象限工作法]]：

```
            紧急
              │
    Ⅱ 重要    │    Ⅰ 重要且紧急
    不紧急    │    （立刻做）
              │
──────────────┼──────────────
              │
    Ⅳ 不重要  │    Ⅲ 不重要但紧急
    不紧急    │    （可以不做/委托）
              │
```

> 大多数人被Ⅰ和Ⅲ牵着走。真正的高手花 70% 时间在Ⅱ（重要但不紧急）——这是长期积累的来源。

### 西蒙学习法

来自 [[../2026-03-14_087_西蒙学习法]]：

> 拆大目标 → 持续专注 → 阶段性反馈。核心：拆分足够细，**每一步的完成都能被感知到**。

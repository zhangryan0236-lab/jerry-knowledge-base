## 一句话定义

思维工具 = 可以刻意安装和分析的**认知框架**，帮助你在复杂信息中提取结构、识别偏见、提升判断质量。

## 核心工具

### 1. 文理科思维差异：理解不同学科的底层逻辑

来自 [[../2025-05-24_005_文理科思维差异]]：

| 理科思维 | 文科思维 |
|---------|---------|
| **线性**：A→B→C，串联推理 | **多视角**：同一事件不同人不同解读 |
| 追求**客观真理** | 追求**价值靠拢**（哪个选项更接近） |
| 答案是唯一的 | 答案是最优的（删除正确选项后还能选） |
| 研究"规律的世界" | 研究"人的世界" |

**应用**：
- 学理科时用线性思维：把问题拆成链条
- 学文科时用多视角思维：切换不同立场理解同一件事
- 不要用理科思维学历史（"哪个选项是正确答案？"→ 历史没有唯一正确答案，只有最优解释）

### 2. 批判性思维：观点 vs 事实

来自 [[../2025-11-02_054_批判性思维之观点与事实]]：

> 批判性思维的起点：能区分**观点**（我认为）和**事实**（可以验证）。

| 观点 | 事实 |
|------|------|
| "这门课很难" | "这门课的挂科率是 30%" |
| "他不努力" | "他上次考试不及格" |
| 主观判断 | 可以验证 |

**日常训练**：每看到一个陈述，问自己——这是观点还是事实？有什么证据支持？

### 3. 归因方法论

来自 [[../2026-02-11_082_归因]] 和 [[../2025-10-03_046_复盘的底层逻辑]]：

> 归因时，把自己当作整个事情中的**一个元素**。事情里有你，你不是事情的全部。

**客观归因公式**：
```
结果 = 自身因素 + 他人因素 + 环境因素 + 随机因素
```

不夸大任何一个因素，也不忽略任何一个因素。

### 4. 打破信息茧房

来自 [[../2025-07-18_023_如何打破信息茧房]]：

> 算法给你想要的 → 你只看想要的 → 你的世界越来越窄。打破茧房需要**主动接触你不认同的信息**。

### 5. 认知提升体系

来自 [[../2026-06-17_114_提升认知]]：

> 认知提升 = 搭建自己的知识体系。不是碎片化阅读——是系统性地建立概念之间的连接。

## 大脑科学

### DMN（默认模式网络）

来自 [[../2026-04-29_099_DMN]]：

> 胡思乱想的生理基础：DMN 是大脑在"闲置"时自动激活的网络。不是你的错——是你大脑的设计。

**应对**：当 DMN 过度活跃时，用**任务正网络（TPN）** 覆盖它——即投入到一件需要专注的事情中。行动是最好的"停止胡思乱想"的方法。

### 脑雾

来自 [[../2025-12-10_065_脑雾]]：

> 脑雾 = 大脑像蒙了一层雾，反应慢、注意力差。常见原因：睡眠不足、压力过大、营养失衡、长期不运动。

### ADHD

来自 [[../2025-12-28_071_ADHD]]：

> ADHD 不是"不专心"——是**注意力调控系统的功能差异**。真正的 ADHD 需要专业诊断。大多数人只是注意力需要训练。

## 与哲学工具的衔接

以上思维工具与 [[哲学与底层思维]] 中的框架深度融合：
- **笛卡尔逻辑法** → 怀疑→分解→综合→穷举（科学思维）
- **征候阅读法** → 读可见与不可见结构（结构主义）
- **批判性思维** → 区分观点与事实（英美分析哲学基础）
- **文理科思维** → 唯物（客观规律）vs 唯心（多主体视角）

# 复盘系统

> 为所有系统提供数据和升级指令。最后一个停机的系统。
> 复盘不替代行动——复盘为下一次行动提供校准。

## 节奏

| 频率 | 时间 | 内容 |
|------|------|------|
| 每日 | 5分钟 | 最重要/卡住了/明天第一件事 |
| 每周 | 15分钟 | 数据表+改1件事 |
| 每月 | 30分钟 | 审视系统本身（不是学习内容） |

## 复盘边界（最重要）

- 每日复盘：5分钟。闹钟响就停。
- 超出5分钟的念头→写在纸上→归入"本周待分析"
- 学习时段不复盘。复盘时段才复盘。

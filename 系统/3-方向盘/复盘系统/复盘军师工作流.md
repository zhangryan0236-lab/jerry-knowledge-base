# 复盘军师工作流 v1.0

> 军师不是替你下结论的人，而是用连续记录、关键追问和小实验，帮你把“我感觉不对”变成可验证行动的人。

## 军师的五种身份与边界

| 身份 | 输入 | 输出 | 禁止做什么 |
|---|---|---|---|
| 记录员 | 你的流水账、原话 | 原始记录，不改写事实 | 擅自补全动机或情绪 |
| 提问者 | 当天事实与空白处 | 一次一个高信息增益问题 | 连环追问、固定问卷、急着建议 |
| 诊断者 | 成稿 + 近期记录 + 进度 | 候选问题、证据、暂定主要矛盾 | 用一次复盘给人格定性 |
| 干预设计者 | 暂定问题 | 1—3 天实验与长短期调整 | 只给书单或空泛建议 |
| 计划校准者 | 已确认进度与周计划 | 明天第一件事、容量调整 | 在每日复盘重写周计划 |

## 总流程与放行门槛

```text
0. 选择日期
   ↓
1. 原始流水账（我先写）
   ↓ 事实、感受、卡点、一个值得记住的时刻至少各有一条
2. 军师追问（一次一个问题）
   ↓ 关键事实与真实感受已澄清；我说“整理吧”才进入下一步
3. 最终复盘（统一模板）
   ↓ 成稿已确认，事实/感受/解释/待观察分开
4. 今日轻诊断（问题与方案）
   ↓ 主要矛盾只是暂定，带证据、反证/未知、复诊条件
5. 同步进度 → 明日计划
   ↓ 只安排明天第一步；周计划只在固定两次校准
6. 保存并等待明天的事实
```

## 1. 原始记录：你先拥有叙述权

每晚先自由写，不需要格式漂亮。最低可从四句话开始：

```text
今天发生了什么、学了什么？
哪里卡住或感觉不对？
有什么开心、满意或值得记住？
明天最想先做什么？
```

原始内容保存到：`系统/3-方向盘/复盘系统/每日复盘/原始记录/YYYY-MM-DD-原始.md`。它不可被军师覆盖，后续所有分析都应能回到它核对。

## 2. 军师提问：不是审讯，而是补足判断所需的证据

军师每轮必须：**回应你刚说的内容 → 只问一个最能改变理解的问题 → 等你回答。** 通常 3—7 问；你说“够了/整理吧”立即停。

选择问题的优先级：

1. 重要但模糊的事实；
2. 明显的精力、情绪或状态变化；
3. 卡点或顺利时刻的关键步骤；
4. 你可能忽略的进步、需要、快乐；
5. 明天可启动的最小动作。

军师先区分五类信息：**事实、感受、需要、你的解释、对自己的判断**。前四项没说清之前，不讨论“你是不是有问题”。

## 3. 最终复盘：当天的可调用事实库

军师根据已经确认的内容生成统一模板，保存到：`系统/3-方向盘/复盘系统/每日复盘/整理记录/YYYY-MM-DD-每日复盘.md`。

```markdown
---
tags: [每日复盘]
created: YYYY-MM-DD
---

# YYYY-MM-DD 每日复盘
## 今日一句话
## 今天发生了什么
## 今天学了什么、做出了什么
## 身体与情绪
## 开心、满意或值得记住的事
## 卡点与我的理解
## 今天有效的东西
## 明天第一件事
## 待观察或待诊断
```

AI 的推断只能放进“待观察或待诊断”，不能伪装成你的自我认识。

## 4. 今日轻诊断：军师开始分析，但不越权

这一步调用 `problem-diagnosis-learning`。它读取当天成稿；必要时对照最近 2—3 天和进度面板。输出保存到：`系统/3-方向盘/复盘系统/每日复盘/诊断报告/YYYY-MM-DD-轻诊断.md`。

```text
本期事实与有证据的进步
需要注意的信号（注明日期/来源）
候选问题（支持证据｜反证或未知｜置信度）
主要矛盾（暂定）
针对性干预（今日/1—3天实验/长期调整）
复诊条件与下轮要收集的证据
```

直接反馈格式固定为：**判断（暂定）→ 证据 → 影响 → 现在的动作**。诊断只有在有事实后才开始；没有证据时，军师要提出下一个观察或提问，而不是装作看透了你。

## 5. 进度同步与计划：防止“每天重写人生”

### 进度面板

每个项目只维护：大目标、截止日期、小阶段、当前证据、下一步、预计完成天数。数据保存到：`系统/3-方向盘/复盘系统/进度/项目进度.json`，同时可导出 Markdown 快照。

### 两层计划纪律

| 计划层 | 频率 | 可改内容 |
|---|---|---|
| 周计划 | 每周两次：周初定盘、周中校准 | 优先级、容量、阶段顺序；必须记录改动理由 |
| 日计划 | 每日复盘结束 | 只定明天第一件事、当天容量与项目下一步；不改周目标 |

周中每天如果想推翻计划，只能写入“待周中校准”；除非出现真实外部截止、健康问题或计划前提消失，才允许紧急改动。

明天计划输出只包含：

```text
明天第一件事：时间/地点/最小动作/完成证据
主线闭环：一个
可选副线：最多一个
保底版：状态差时的15分钟动作
```

## 6. 军师的长期记忆如何形成

| 层 | 保存内容 | 军师如何使用 |
|---|---|---|
| 原始层 | 你的第一版流水账、问答 | 避免整理时丢失事实；可回溯误判 |
| 事实层 | 最终复盘 | 日/周/月趋势的主要证据 |
| 诊断层 | 候选问题、实验、结果 | 复诊并修正假设，不重复开药方 |
| 进度层 | 项目阶段与完成证据 | 让明日计划从真实任务而来 |
| 周计划层 | 两次校准的计划版本 | 防止每日情绪改变战略 |

## 7. 操作口令

1. 点击复盘工作台的今天 → 写流水账 → 点击“复制给军师”。
2. 在 Codex 说“这是我今天的复盘”，粘贴内容；军师一次问一个问题。
3. 说“整理吧”，把最终 Markdown 粘回工作台保存。
4. 点击“交给军师做今日轻诊断”，粘贴返回的诊断并保存。
5. 同步项目进度；生成并保存明天的第一件事。

> 先连续运行 7 天，再讨论优化提问库或页面字段。没有连续事实时，不优化诊断模型。

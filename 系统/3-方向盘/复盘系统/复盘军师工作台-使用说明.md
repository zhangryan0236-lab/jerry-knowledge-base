# 复盘军师工作台

一个本地优先的每日复盘界面，用于把“流水账”逐步变成可被 AI 军师追问、诊断和推进的行动系统。

## 包含内容

- `复盘军师工作台.html`：直接在 Edge/Chrome 中打开的工作台。
- `复盘军师工作流.md`：军师的提问、诊断、进度与计划边界。
- 本说明文件。

## 快速开始

1. 双击打开 `复盘军师工作台.html`。
2. 在左侧从上到下运行：**复盘 → 军师追问 → 指出问题 → 同步进度 → 列好明日计划**。
3. 复盘页点击一个日期；悬停已有记录的日期可预览当天内容。
4. 点击“复制给军师”，把文本粘贴到 Codex。军师应一次只问一个问题。
5. 完成后点击“选择本地保存文件夹”，选择本目录下的 `每日复盘`，再点击“保存当前日期记录”。

## 本地存档

工作台会在所选文件夹内创建并写入：

```text
每日复盘/
├── 原始记录/      # 原始流水账与军师问答
├── 整理记录/      # 确认后的最终复盘
├── 诊断报告/      # 今日轻诊断、实验与复诊条件
└── 进度/          # 项目阶段与明日计划
```

浏览器本地存储仅用于临时恢复；Markdown 和 JSON 文件才是你的长期数据源。

## 设计原则

- 没有事实，不诊断；
- 军师先追问，再给方案；
- 每日只安排明天，周计划只在周初定盘与周中校准时修改；
- 诊断结论必须区分事实、你的解释与待验证假设。

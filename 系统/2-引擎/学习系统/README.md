# 学习系统

> 主引擎。每天最核心的运行模块。
> 注意力 → 输入 → 处理 → 输出 → 错误反馈 → 睡眠巩固

## 输入协议（按来源分类）

| 来源 | 协议 | 关键原则 |
|------|------|---------|
| 网课/视频 | 三次过法：暴露→加工→提取 | 第一遍记不住正常，不要自责 |
| 教材/书籍 | 三明治：扫读→深读→关联 | 合上书回忆，不划线 |
| 碎片信息 | 一句话记录→周末集中处理 | C类不做深度处理=48小时内遗忘 |

## 处理深度（忽然知己四层次）

复述 → 解释 → 迁移 → 批判

## 输出

- 费曼自检："能给初中生讲清楚吗？"
- 做题：错误=数据，不是审判
- 笔记卡片：一句话定义+核心要点+错因+关联

主动回忆：
这个主动回忆可以是一个章节的知识体系，一个是我背的内容，还有什么是我需要主动回忆的，比如我去看高等数学或者计算机组成原理
但是主动回忆的内容难度是有区别的。例如，回忆整章重点时，难度较高，需要对整个大章节有深度理解；而回忆小块内容时，只需掌握其重点内容和关键词即可。
但是对于一个大的章节，我去主动地进行回忆，第一次如果回忆不出来，那第二次也回忆不出来，第三、第四次也回忆不出来，那我下一步该怎么做？

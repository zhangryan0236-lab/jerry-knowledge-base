# 计划与执行力

> 启动引擎。决定今天做什么和怎么启动。
> 核心原则：休息 > 工作。计划的核心不是排满——是怎么留白。

## 协议

| 协议 | 内容 |
|------|------|
| 日计划 | 前一天晚上写"明天第一件事"（一个具体动作） |
| 周计划 | 周六15分钟，只改1件事 |
| 月计划 | 审视系统本身 |
| 启动协议 | 打开昨天复盘→看最后一行→做那件事。不判断状态。 |
| 中断恢复 | 断1天：接上。断2天：过渡日。断3天+：最简版。 |

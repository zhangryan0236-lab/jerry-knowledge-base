# 习惯系统

> 自动引擎。目标是让大部分学习行为不需要意志力参与。
> 身份驱动 > 习惯驱动 > 鸡血驱动

## 核心习惯（每天必须做）

1. 同一时间坐在桌前
2. 至少跑 1 个闭环（55分钟/15分钟）
3. 睡前写 3 个问题
4. 说一句"今天我出现了。我是学习者。"

## 四法则应用

| 法则 | 做法 |
|------|------|
| 让它显而易见 | 书永远摊开在桌上；手机放另一个房间 |
| 让它有吸引力 | 跑完闭环→允许看10分钟手机 |
| 让它容易做 | 最低版只需15分钟 |
| 让它令人满足 | 日历画❌，连续记录可视化 |

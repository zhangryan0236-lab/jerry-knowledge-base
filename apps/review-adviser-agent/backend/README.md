# 后端 MVP

当前实现：

- FastAPI 健康检查；
- SQLite 保存复盘线程，支持关闭网页后用 `thread_id` 恢复；
- LangGraph 驱动单轮“回应 + 一个问题”；
- 未配置模型 API 时使用本地降级追问，便于验证归档与恢复；
- 原始复盘自动写入 `系统/3-方向盘/复盘系统/每日复盘/原始记录`；
- 用户回复“整理吧”后写入整理记录，且永不覆盖同名文件。
- 项目面板保存真实的下一步、阶段、阻塞和完成证据；复盘出现明确完成表述时自动追加证据。
- 本地驾驶舱由 FastAPI 直接提供，默认仅监听 `127.0.0.1`。

尚未实现：跨期诊断、事实切片与证据卡、受约束 RAG、微实验与周计划守卫。这些将按启动规格逐步增加。

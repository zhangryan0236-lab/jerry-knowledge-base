# 投放给军师

把希望复盘军师读取或使用的内容放在对应子文件夹中。

## 文件夹说明

- `军师参考资料/`：书籍摘录、学习方法、心理学/脑科学材料、公众号或视频转写。军师后续只会从你明确放入这里的内容建立受约束的参考知识库。
- `待整理复盘/`：你已有但尚未进入系统的日记、周复盘、月复盘。
- `界面参考/`：你喜欢的产品截图、链接说明、手绘草图。用于界面重做时对齐审美。
- `模型配置/`：保留模型配置示例和说明。
- `大模型的API.env`：唯一实际生效的本地模型配置文件。填写后，军师会从这里读取模型地址、密钥和模型名。**不要把密钥发到聊天里。**

原始材料不会被程序改写；整理、索引和向量数据会写到应用的 `runtime/` 目录。

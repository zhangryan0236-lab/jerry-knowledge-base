# AI使用心法

> 姜胡子对AI的态度经历了明显的演化：从"工具"到"咨询师/良师益友"，但始终保持一个核心边界——**AI是增强器而非替代品**。

## AI角色演化

### 早期（2025上半年）：AI是工具
> "不要把AI仅仅当作工具，他可以是你的咨询师、顾问，良师益友。" → [[2025-02-04_020_不要把AI仅仅当作工具]]

这个表述本身就包含了张力——"不要仅仅当作工具"意味着它比工具更多。

### 中期（2025年中）：AI三重境界
> [[2025-04-25_052_如何使用AI，三重境界]]

三重境界：
1. **问答** — 问AI问题，获得答案
2. **对话** — 与AI深入对话，验证和加深理解
3. **协作** — AI融入工作流，成为系统的一部分

### 后期（2026年）：AI+知识库
> [[2026-07-04_459_AI+知识库，我的工作台长这样]]

AI已深度集成到知识管理系统中：
- AI了解你的知识库结构
- AI自动建立新旧知识的连接
- AI输出可执行的方案或待办项
- AI监控技能使用频率

## AI使用的四大原则

### 1. AI是帮助你学习的，不是替代你学习的

> "你怎么用AI读书？我从来不用AI帮我读书。不是不读书，是不让AI替我读书。" → [[2026-06-30_455_用AI读书的正确姿势]]

**AI辅助读书四步法**：
| 步骤 | AI做的事 | 你做的事 |
|------|----------|----------|
| 1 | 总结书的论证框架 | 判断是否合理 |
| 2 | 找出与你的认知冲突的点 | 感受"摩擦" |
| 3 | 推荐最应该读的章节和顺序 | 决定读什么 |
| 4 | 不参与 | 亲自阅读 |

> "知识学习是'安装'不是'下载'。"

### 2. AI是你的翅膀，但不能替你飞翔

> "学习新东西最忌讳什么？就是用你旧有的认知去评价它。" → [[2026-05-02_396_我的极速学习系统]]

- AI可以帮你快速进入新领域
- 但理解、判断、决策必须自己做
- "如果你对世界没有自己的判断，AI给你的东西你无法辨别好坏"

### 3. AI处理逻辑，你处理情感和判断

> "你自己没逻辑，AI可以帮你有逻辑，但AI没情感。他不懂人，你是人。" → [[2026-03-17_349_成事之法 Pro版]]

分工：
- AI → 整理、归纳、结构化、自动化
- 人 → 判断、情感、价值观、方向选择

### 4. AI需要被正确"编程"

> "文章就是源代码。你只要写清楚背景、问题、方法、原因，AI就能执行。" → [[2026-03-17_349_成事之法 Pro版]]

这个"文章即代码"的概念将写作提升到了新高度：
- 写文章不只是表达，也是在给AI下指令
- 好文章 = 好的prompt = 可执行的方案

## AI+知识库实操

来源：[[2026-07-04_459_AI+知识库，我的工作台长这样]]

### 目录结构 (PARA+扩展)
```
知识库/
├── Inbox/      → 灵感收集（待处理）
├── Project/    → 正在做的事
├── Asset/      → 已处理的个人知识
├── Resource/   → 外部参考资料
├── Archive/    → 归档
└── Skills/     → 标准化操作模板
```

### AI协作流程
1. 告诉AI你的目录结构
2. AI自动识别文件属性
3. 新知识进来 → AI自动建立与旧知识的连接
4. AI生成可执行方案或待办项
5. AI监控技能调用频率 → 提醒未使用的技能

## AI在创作链中的应用

### 内容创作
来源：[[2026-03-16_348_我的10x短视频创作方法]]

**"说"和"写"分离**：
1. 先用"说"（录音/语音）把思路倒出来 → 不用管逻辑
2. AI帮你整理、结构化
3. 你对着AI的输出再"说"一遍（更流畅）
4. 形成文字稿 → 拍摄

### 流水线工业化创作
来源：[[2026-02-24_327_流水线工业化创作灵感]]

> "创新 = 旧要素(Old Elements) × 新连接(New Connections)"
- AI帮助实现要素的排列组合
- 人负责判断哪些组合有价值

### AI帮你节省90%的时间
来源：[[2026-05-15_409_你的时间，被偷走了]]

> "你花在选题、找素材、写稿、拍剪上的时间，90%都是可被替代的。"
- AI替代重复性工作
- 人专注于判断和创造力

## 姜胡子与AI的独特关系

他使用AI的方式有一种独特的工程师气质：

1. **不把AI当黑箱**：要理解AI能做什么、不能做什么、边界在哪里
2. **系统性集成**：AI不是独立的工具，是嵌入整个工作流的一个组件
3. **人机分工明确**：AI负责逻辑和重复，人负责判断和创造
4. **渐进式深度使用**：从简单问答 → 对话验证 → 知识库集成 → 系统自动化

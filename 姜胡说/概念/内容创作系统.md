# 内容创作系统

> 姜胡子关于自媒体/短视频/内容创作的方法论体系。这是他内容中第二大主题（约80+条笔记），也是他最实操的领域。

## 核心理念

### 有用 + 真实 = 变现基础
> "做短视频其实就两个，一个是有用，一个是真实。" → [[2026-05-22_416_做短视频的大部分人都在做错的事]]

姜胡说区别于大多数"自媒体导师"的核心：
- 不教爆款技巧 → 教的是"做事 → 思考 → 记录 → 分享"的本源流程
- 不追热点 → 追"常热点"（持续有需求的话题）
- 不设计人设 → 人设是做出来的
- "短视频只是结果，真正重要的是：做事→思考→记录→分享→改进" → [[2026-04-01_364_我是怎么拍短视频的？]]

## 创作方法论

### 抄操超钞 (Copy → Practice → Surpass → Monetize)

来源：[[2025-08-01_137_抄操超钞，认真做好一件小事]]

| 阶段 | 含义 | 具体做法 |
|------|------|----------|
| **抄** | 像素级复刻 | 找粉丝少但点赞多的视频，拆解结构，模仿拍摄 |
| **操** | 反复练习 | 别人拍一条你拍两条，练到肌肉记忆 |
| **超** | 超越创新 | 在模仿中形成自己的风格和理解 |
| **钞** | 商业变现 | 有了内容能力和用户后自然变现 |

深度版 → [[2025-10-19_213_抄、操、超、钞 视频创作三层进阶]]

### 王者拍摄法

来源：[[2025-09-12_176_王者拍摄法]]、[[2026-01-08_288_王者拍摄法plus+]]

**核心理念**：情绪先于内容
> "情绪是你与观众之间的桥梁，只有架好这座桥，内容才能过去。"

**一镜到底法**：用演讲的方法做口播
- 一镜到底，无需剪辑，节省大量时间
- 知识密度和深度是核心竞争力
- 来源：[[2025-08-15_151_降维打击 用演讲的方法做口播]]

### 超级王者拍摄法

四位AI导师辅助：
1. **私人助理**：从0到1生成初始脚本
2. **灵魂导师**：优化深度和角度
3. **批判家**：找漏洞和不足
4. **剪辑师**：结构优化

来源：[[2025-09-28_193_超级王者拍摄法]]

### 爆款选题5步法

> "选题决定爆款上限，比黄金3秒还重要" → [[2025-10-02_197_爆款选题5步法]]

3. 搜索关键词（发现高频问题）

5. 形成选题库

### AIDA框架

- **A**ttention — 吸引注意
- **I**nterest — 引发兴趣
- **D**esire — 激发欲望

### 内容创作系统 (工业化版本)

来源：[[2026-03-28_360_短视频风容创作系统]]

**三阶段模型：**
1. **试错期（及时止损）**：多发、多试、看数据、快速淘汰
2. **构建系统（输入-处理-输出）**：灵感库+知识库分离，形成标准化流程
3. **形成闭环（数据反馈）**：根据数据反馈持续优化

**知识卡片格式：**
- 一句话总结
- 解决了什么问题
- 操作步骤
- 边界条件（什么情况适用/不适用）

**关键区分：灵感库 vs 知识库**
- 灵感需要发散（自由联想）
- 创作需要收敛（聚焦执行）
- 混在一起 = "一脚油门一脚刹车"

### 流量力学

来源：[[2026-04-20_384_流量力学]]

**三个角色：你 + 平台 + 用户**

| 角色 | 需求 | 你给什么 |
|------|------|----------|
| 平台 | 商业价值 + 用户注意力 | 帮平台留住用户 |
| 用户 | 功能价值 + 情绪价值 | 解决问题 + 情感共鸣 |
| 你 | 影响力 + 收入 | 持续输出有用内容 |

**核心洞察：**
- 算法是平台意志的代理，只看用户行为数据
- 算法会变，但人性不变
- 逆向工程：分析成功者的**结构**（不是内容），理解每个结构触发了什么行为

### 日更拍摄法

来源：[[2025-10-31_223_日更的拍摄]]

**日更的本质**：不是每天都从0到1创作
- 建立知识库 → 每日回顾 → 发现可分享的点 → 自然产出
- "日更不是在创作新内容，是在整理和分享已有的思考"

### 镖人创作法

来源：[[2025-10-16_210_镖人2025，一个既简单但有效的创作方法]]

**从"作品"降级到"记录"**：
- 不要想着每条都是作品
- 记录真实的学习过程、赚钱过程、成长过程
- 真实的过程就是最好的内容

来源：[[2026-06-17_442_一面对镜头就忘词？问题不在记性]]、[[2025-11-26_249_提升能力及影响力的三条策略]]

- 每天对着镜子练习

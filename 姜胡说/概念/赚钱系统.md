# 赚钱系统

> 姜胡说关于赚钱/财富的核心思想体系。这是他内容中占比最大的主题（约120+条笔记）。

## 核心公式演化

### 1.0 基础公式
**(喜欢 + 社会需求) × 擅长 × 1000**
- 喜欢 → 爱觉不累、专注投入
- 社会需求 → 健康、财富、关系、自我实现
- 擅长 → 信息差、认知差、行动差、竞争差
- ×1000 → 影响力放大
- 来源：[[2025-01-19_008_一条公式]]

### 2.0 财富路线图
**(热情 + 社会需求) × 能力 × 影响力**
- 更强调"找到交集"而非单纯喜欢
- 能力部分深化为四个差值
- 来源：[[2025-04-02_042_财富路线图]]

### 3.0 赚钱本质公式
**收入 = 产品 × 用户数 × 复购** (vs 收入 = 时间 × 时薪)
- 做乘法不做加法
- 打造可复用资产而非卖时间
- 来源：[[2025-10-22_217_做副业，必须做乘法，不要做加法]]、[[2025-09-21_186_我是怎么一边学习一边赚钱的]]

### 4.0 财富飞轮
**每天写 → 每天拍 → 每天分享 → 积累用户 → 打磨产品 → 收入增长**
- 来源：[[2026-01-02_282_我的个人财富增长飞轮]]

## 四差理论

姜胡说认为赚钱的本质是创造并利用"差值"：

| 差值类型 | 定义 | 商业含义 |
|----------|------|----------|
| **信息差** | 我知道你不知道 | 搬运信息、跨平台套利 |
| **认知差** | 你以为知道但不知道（不够深） | 深度解读、降维打击 |
| **行动差** | 别人不做你来做 | 执行力本身就是壁垒 |
| **竞争差** | 做同样的事你更好 | 质量、效率、体验的差异化 |

> "水往低处流"——有了差值，价值自然流动。

## 赚钱的几条路径

### 路径一：解决问题
**发现别人的痛苦 → 提供解决方案 → 收钱**
- 核心信念："赚钱的本质是解决别人的痛苦" → [[2025-12-16_270_赚钱之法]]
- 从自己的问题出发 → 找到共性需求 → 产品化
- "发现商机" → [[2025-03-18_036_发现商机]]

### 路径二：信息差套利
**把你会的教给不会的人**
- "二年级教一年级" → 多处引用
- 信息差赚钱 → [[2025-06-15_092_我的一个赚钱的方法：信息差]]、[[2026-04-13_377_到底什么是信息差？怎么用信息差赚钱？]]

### 路径三：能力产品化
**把你的技能变成可复用的产品**
- 知识付费、课程、专栏、社群
- "能力 ≠ 财富。财富 = 产品 × 杠杆 × 规模" → [[2026-03-02_333_能力产品化]]
- 7种知识博主赚钱方式 → [[2025-12-05_258_我的收入来源]]

### 路径四：销售（分享式）
**分享 > 推销**
- "最好的销售是分享" → [[2025-10-03_198_最好的销售：不卖而卖]]、[[2026-02-01_312_最好的销售方法]]

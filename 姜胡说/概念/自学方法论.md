# 自学方法论

> "自学是我的终极技能。"——姜胡说，中专出身，所有赚钱的方法都是自学获得的。

## 核心理念

### 自学是第一元技能
> "自学能力是最基础的元技能，你可以用它换任何东西。" → [[2026-03-11_343_自学能力是最基础的元技能]]

姜胡说的个人标签：
- 中专生 → 程序员 → 创业者 → 投资人 → 咨询师 → 自媒体人
- "我几乎所有赚钱的方法都是通过自学获得的" → [[2026-05-26_420_我的自学方法]]

## 三阶段学习法

### 拆解 → 对应 → 落地

来源：[[2026-05-26_420_我的自学方法：拆解→对应→落地]]

**第一步：拆解**
- 找到"做得好的人" → 直接拆解他的方法
- 引用科比：所有场上动作都是看录影带学来的
- 关键不是结果，而是**约束条件**：在什么情况下、用什么方法、如何解决问题的
- 不需要报班、不需要老师

**第二步：对应**
- 将知识与自己的真实生活/工作状态对比
- "人家是怎么做的，我是怎么做的"
- "哪些事我做对了，哪些事没做好"
- AI可以辅助做这个对应

**第三步：落地**
- 将知识融入自己的系统中
- 如果能自动化就变成习惯/程序
- 如果不行就变成任务清单，定时提醒
- AI监控执行情况：哪些技能用了多少次，哪些从来没有用过

### 日常实践：三块工作法
每天2小时分成三块：
1. **30分钟**：理解一个关键概念
2. **30分钟**：与自己的实际生活和工作对应
3. **60分钟**：落实到系统中

## 其他学习方法

### 问题驱动学习
> "真正的高手不是学完知识再用，而是先有要解决的问题，再去学需要的知识。" → [[2025-09-21_186_我是怎么一边学习一边赚钱的]]

对比：
- ❌ 传统：系统学知识 → 再想怎么用 → "知识溺水"
- ✅ 高效：明确要解决的问题 → 需要学什么 → 学完立刻用

### 关键词读书法
> "读完就忘？因为顺序错了。" → [[2026-05-07_401_关键词读书法]]

1. 先看目录，找关键词
2. 带着问题去读相关章节
3. 读完立刻用

## 学习 vs 消费

姜胡说反复强调一个区分：

| 假学习（消费信息） | 真学习 |
|-------------------|--------|
| 划线、收藏、下载 | 理解、对应、落地 |
| 刷视频、买课 | 用出来、做出来 |
| 追求系统完整 | 追求解决问题 |

## 学习与赚钱的闭环

这是姜胡说最具特色的方法论——**一边学习一边赚钱**：

1. 学一个东西 → 
2. 解决了自己的某个问题 → 
3. 把过程和结果分享出去（朋友圈、视频） → 
4. 别人也有同样的问题，来找你 → 
5. 免费分享/组织活动 → 
6. 发现更多需求 → 打磨产品 → 
7. 判断是否值得做（利润×用户数×复购） → 
8. 滚雪球

来源：[[2025-09-21_186_我是怎么一边学习一边赚钱的]]、[[2025-06-18_095_一边学习，一边赚钱]]

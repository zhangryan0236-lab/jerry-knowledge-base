## 认知升级路径

### 1. 认知觉醒：我们对世界的理解可能是错的

> "阻碍你发展的不是无知，而是你固有的成见。" → [[2025-10-08_202_我们对这个世界的理解很可能是错的]]

**箱子轮子的故事（核心隐喻）**：
- 1989年之前，所有人都认为"箱子=手提=装东西"
- 所有的创新都在空间和材质里打转
- 普拉斯给箱子装了轮子 → 打破了定义 → 移动性
- **启示**：固有定义限制了我们看待世界的方式

**自省方法**：
- 记录自己"深以为然的理解"
- 拿出来仔细思考："这个理解对吗？"
- "如果你对世界的理解是对的，你的口袋里应该已经有了你想要的东西。"

### 2. 身份升级：从打工者到成事者

来源：[[2026-02-13_324_真正的成长是身份的升级]]

| 打工者/能力者 | 成事者/创业者 |
|-------------|-------------|
| "我学到什么技能？" | "怎么搞定这件事？" |
| 关注个人能力提升 | 关注问题被解决（不限方式） |
| 追求"我是对的" | 追求"事成了的" |
| 能力是终点 | 能力是起点 |
| 被问题解决 | 解决问题 |

**关键故事**：10多年前参加阿里老师课程，他能力最强但最终是"解决问题的人"，而两个经常表扬他、加他微信的朋友后来成为"成事者"——因为他们擅长的不是解决问题，而是"让事成"。

### 3. 认知建筑学：学以致用

来源：[[2025-09-19_184_认知建筑学，学以致用的方法]]

> "很多人学了大量知识，却无法应用。问题不在于知识量不足，而在于知识没有'建筑学'结构。"

- 知识需要有一个承重结构
- 新知识必须嵌入到现有结构中
- 否则就是一堆散落的砖块

### 4. 搭建认知系统

来源：[[2026-01-06_286_搭建认知系统]]

> "人和人最大的差距是认知。认知不能直接帮你赚钱。但认知决定你赚多少钱的上限。"

框架：认知 → 决策 → 行动 → 结果

### 5. 认知系统二：如何做决策

来源：[[2026-01-13_293_认知系统二：如何做决策]]

**财富铁律**：收入 → 结余 → 投资

## 认知陷阱诊断

姜胡子识别并命名了多种认知陷阱：

### 脑袋里的4个病毒
来源：[[2026-01-22_302_脑袋里的4个病毒]]
1. "证明自己是对的"病毒
2. "等准备好了再开始"病毒
3. "别人怎么看我"病毒
4. "已经来不及了"病毒

### 穷富思维差异
来源：[[2026-03-24_356_穷富思维差异：用时间换钱vs花钱买时间]]

| 穷人思维 | 富人思维 |
|----------|----------|
| 用时间换钱（加班、接单） | 花钱买时间（购买别人的时间/经验/系统） |
| 没时间思考 → 死循环 | 有时间思考 → 正向循环 |
| 省钱 | 投资 |
| 赚了钱就消费 | 赚了钱买资产 |

**破局**：先改变思维 → 识别重复劳作 → 构建工具/模板/流程 → 卖工具给富人 → 用收入买更多时间

### 为什么越努力越穷
来源：[[2025-12-14_267_为什么越努力越穷？因为你做的事不值钱。]]

> "想象一条河。你站在下游捞水，上游的人控制着水源。"

- 位置比努力重要
- "上游" = 认知优势、信息优势、关系优势

### 位置比聪明重要
来源：[[2026-07-01_456_位置比聪明重要，烂牌可以换一桌人打牌]]

> "开局拿了一手烂牌怎么办？大多数人就是更努力地打牌。但你要做的是换一桌。"

### 你在用叙事的解法解结构的题
来源：[[2026-05-11_405_越刷视频越焦虑？你在用叙事的解法解结构的题]]

> "越刷视频越焦虑？因为你用叙事的解法，去解结构的题。"
- 叙事解法：个人努力、心态调整、励志故事
- 结构解法：系统设计、规则改变、位置调整

## 认知的关键转变

### 从"证明正确"到"验证有用"
> "2023年我投资亏了近40%。因为我一直在证明自己是对的。后来我改成验证有没有用。" → [[2025-11-08_231_有用优先于正确]]

### 从"怕失败"到"主动犯错"
> "通往成功最快的路就是主动去犯错。" → [[2025-09-01_167_快去犯错]]

### 从"收集证据证明我不行"到"找方法"
> "很多人在面对困难时，不是寻找解决方法，而是收集自己'不行'的证据。" → [[2025-08-27_162_我有证据证明'我不行']]

### 从"消费者"到"生产者"
> "钱是交易的媒介。花钱的人叫消费者，赚钱、提供产品的人叫生产者。" → [[2025-04-07_043_生产者&消费者]]

### 从"学校思维"到"市场思维"
> "离开学校的那天，卷子就没了。原以为规则固定的游戏才是好游戏——因为你跑在学校里。" → [[2026-05-23_417_离开学校的那天，卷子就没了]]

### 从"确定性依赖"到"概率思维"

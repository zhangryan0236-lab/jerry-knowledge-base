# 复利与系统思维

> 如果说"认真做好一件小事"是执行层面，那么"复利与系统"就是姜胡说思想体系的战略层——它解释了**为什么要做小事、怎么让小事产生大效果**。

## 核心概念：系统

### 系统的定义
> "系统不是靠爆发式努力，而是每天做一件很小、很简单、可持续的事，得到即时反馈，持续做。" → [[2025-12-24_278_最小系统的力量]]

系统的四个特征：
1. **小** — 小到不可能失败
2. **简单** — 不需要意志力
3. **即时反馈** — 做了就有结果
4. **可持续** — 能一直做下去

### 为什么系统比意志力可靠
> "坚持靠意志力，意志力会断电。长期主义真正靠的是系统。" → [[2026-01-29_309_长期主义三大引擎]]

姜胡说多次批判"自律"概念：
> "千万不要太自律。自律只是表象。越是拼命自律的人，失败的可能性越大。" → [[2025-08-25_160_要放松不要自律]]

## 杠杆思维

### 从加法到乘法
姜胡说最重要的思维升级之一：

| 旧公式 | 新公式 |
|--------|--------|
| 收入 = 时间 × 时薪 | 收入 = 产品 × 用户数 |
| 时间有天花板(24h) | 用户数理论上无限 |
| 时薪增长缓慢 | 客单价可以翻倍增长 |
| 手停口停 | 手停钱不停 |

来源：[[2025-10-22_217_做副业，必须做乘法，不要做加法]]

### 三种赚钱方式
1. **出卖体力和时间** → 有天花板
2. **制造可复用的产品** → 一份时间卖多次
3. **购买他人的时间** → 用钱买时间

来源：[[2026-07-06_461_你不是没资源，你是不知道]]

### 10倍增长比2倍容易
> "2倍思维是优化，10倍思维是重构" → [[2026-01-26_306_放大10倍]]、[[2025-09-08_174_10倍增长 比2倍更容易]]

引用 Sam Altman 的观点。

## 财富飞轮

来源：[[2026-01-02_282_我的个人财富增长飞轮]]

```
每天写点什么 → 每天拍点什么 → 每天分享 → 
积累用户和信任 → 打磨产品 → 收入增长 → 
更多动力 → 继续写/拍/分享 → ...
```

关键：这是一个**自增长的飞轮引擎**，越转越快。

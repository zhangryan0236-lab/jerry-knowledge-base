# 成事之法

> "认真做好一件小事"——这是姜胡说所有方法论中重复频率最高的核心理念，也是贯穿他整个内容体系的主线。

## 三大效应（1.0 版本）

来源：[[2025-01-15_004_成事之法]]

### 1. 积累效应 🐸🐌
> "青蛙不一定能跳出深井，蜗牛可以。"

- 不要一开始就想做大事（青蛙蹦不出井）
- 每次做一点，持续积累（蜗牛慢慢爬上去）
- 核心：把大事拆成无数可执行的小事
- 演化：后来成为"最小系统"的理论基础

### 2. 复利效应 📈
> "知识也好，技能也好，做的越多，水平越高。"

- 做事的次数越多，能力越强
- 作者举例：从拍一条视频30-40分钟到拿起手机就能拍
- "最好的投资就是投资自己"
- 演化：后来发展为"每天写点什么"、"财富飞轮"

### 3. 蝴蝶效应 🦋
> "一旦获得了成功，你的起点就不一样了。"

- 做成一件小事 → 有结果 → 吸引资源（人脉、信任、合作）
- 一点小小的改变带来巨大收益
- "你的作品，是最好的名片" → [[2026-01-14_294_成功的第一步]]

## 成事之法 Pro版 (AI时代)

来源：[[2026-03-17_349_成事之法 Pro版]]

**核心升级："文章就是源代码"**

在AI时代，成事的方法进化了：
1. **做成一件小事** → 哪怕1万播放量、1千块副业收入
2. **写一篇文章** → 不讲文采，就讲：背景→问题→解决方法→为什么这样解决
3. **拆分成短视频** → 一篇文章拆成多个知识点块，每块一条视频
4. **接收反馈迭代** → 看评论、修补文章、越改越好
5. **AI加持** → 录音给AI总结→AI帮你梳理逻辑→AI帮你拆分成块
6. **形成飞轮** → 内容有了 → 产品有了 → 用户有了 → 更多内容

关键洞察：
> "没有人会为你的梦想支付费用，但是人们会为他的参与一块来做这个事情买单。"
> "开源你的成功。"

## 为什么做事总失败？

姜胡说在不同时间点诊断了"不成事"的原因：

### 心理障碍
- **怕**：怕准备不足、怕无法达成目标、怕失败 → [[2025-01-20_010_帮你变身]]
- **自尊心太强**：卡住你的主要原因 → [[2026-02-10_321_摆脱自尊心束缚]]
- **收集"我不行"的证据**：不是找方法而是证明自己不行 → [[2025-08-27_162_我有证据证明"我不行"]]
- **拖延**：拖延不是你的问题，是大脑的本能 → [[2025-11-12_235_搞定"拖延症"]]

### 方法错误
- **只想不做**："多数人想了一辈子，一事无成" → [[2026-05-14_408_做了两件事，我成了]]
- **想太多**："还没开始就耗光了能量" → [[2025-10-12_206_普通人怎么把一件事做成？]]
- **等完美**："最傻的方法是先做到完美再发布" → [[2026-04-12_376_没人知道你的过程，你可以从一坨屎开始]]
- **伪勤奋**："大多数人的勤奋是假的" → [[2026-01-21_301_别再伪勤奋了，从观众到工程师，真正有用的学习方法]]
- **92%的计划会失败** → [[2026-01-24_304_92%的计划会失败]]
- **3分钟热度** → [[2025-10-13_207_如何解决 3 分钟热度的问题，顺便赚点小钱]]

### 环境因素
- **不成功的人聚在一起互相抱怨** → [[2025-07-31_136_不成功的秘诀]]
- **努力用错了方向** → [[2026-02-06_317_别把努力用错地方]]

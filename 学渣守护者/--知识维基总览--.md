## 核心框架：状态 > 方法 > 知识点

这是贯穿全部视频的**元模型**（出自 [[../2025-11-14_033_什么决定了我们的成绩？分数背后的逻辑是什么？ 每当考试结束成绩单上的数据起起落]]）：

```
┌──────────────────────────────────────────────┐
│              状态（心态 × 能量）               │
│   ┌──────────────────────────────────────┐   │
│   │        方法（通法 × 学科法）           │   │
│   │   ┌──────────────────────────────┐   │   │
│   │   │    知识点（具体内容）          │   │   │
│   │   └──────────────────────────────┘   │   │
│   └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘

状态崩了 → 再好的方法也用不出来
方法不对 → 补再多知识点也是烟花
知识点漏洞 → 是最后才需要解决的问题
```

**这意味着**：当你成绩出问题时，先检查**状态**（是否内耗/焦虑/睡眠差），再检查**方法**（流程是否科学），最后才看**知识点**（具体哪个章节不会）。

# 知识维基：工作流指南

> 本文档教你如何具体使用这套系统。
> 分三个操作：**摄入**新资料 → **查询**维基 → **巡检**健康。

---

## 🍽️ 操作一：摄入（Ingest）

### 什么时候做？
- 你看完了一篇文章、一个视频、一章书
- 你从 Obsidian Web Clipper 剪藏了一篇网页
- 你记录了一段播客笔记

### 怎么做？

**Step 1：把原始资料放进知识库**
- 如果是网页剪藏 → 保存到 `Clippings/` 或对应的主题文件夹
- 如果是你自己的笔记 → 保存到 `raw/学习日志/`、`raw/抖音视频初次输入/` 等
- 不必整理，保持原始即可

**Step 2：对 AI 说（以下任选一种）**

| 你说 | AI 理解 |
|------|---------|
| "摄入 [[文件名]]" | 读取该文件，提取要点，写入维基摘要页，更新索引和日志 |
| "帮我处理这篇新文章 [[文件名]]" | 同上，更口语化 |
| "摄入 Clippings 里最新的那篇" | 找最新的剪藏，处理 |

**Step 3：AI 执行流程**
```
读取原始资料
  → 和你聊 2-3 个关键要点（你决定侧重什么）
  → 在维基写摘要页
  → 更新维基中相关的概念/实体页面
  → 更新 index.md
  → 在 log.md 追加条目
```

**Step 4：你验收**
- 点击链接看新页面
- 打开图表视图（Graph View）看看连接关系
- 告诉 AI "这里强调不够" 或 "这个部分可以精简"

### 举例
```
你："摄入 [[Clippings/Bilibili/2026-07-15-黑马Vibe Coding...]]"

AI：读取文章 → 和你讨论 "Vibe Coding 的关键思路是什么"
   → 在维基写 "Vibe Coding 摘要页"
   → 更新 "wiki/AI学习/Agent.md" 中相关段落
   → 更新 index.md
   → 追加 log.md
```

## 🔍 操作二：查询（Query）

### 什么时候做？
- 你想回顾某个概念
- 你想比较几个知识点
- 你想看看自己对某个主题理解得怎样了
- 你想从维基中找灵感

### 怎么做？

你对 AI 说（以下任选一种）：

| 你说 | AI 行为 |
|------|---------|
| "维基里关于 [主题] 都说了什么？" | 从 index 找到相关页 → 读取 → 综合回答 |
| "帮我比较 [A] 和 [B]" | 找对应页面 → 做比较表 |
| "[概念] 在我知识库里是怎么定义的？" | 找该概念页 → 提取定义和发展 |

### 进阶用法

**将好答案归档**
当 AI 给出了一个特别有价值的回答，说：
"把这个答案保存为维基页面，放在 [[wiki/XXX]]"

这样你的探索成果会像摄入的资料一样积累。

### 举例
```
你："维基里关于 知行合一 和 交付物 有什么关系？"

AI：读取 [[wiki/核心目标/哲学-知行合一与可证伪性]]
    读取 [[wiki/核心目标/认知心理学-为什么交付物重要]]
    综合回答：二者通过"可证伪的交付物"连接...
    你："把这个保存为页面"
    保存到 [[wiki/比较-知行合一与交付物]]
```

## 🧹 操作三：巡检（Lint）

### 什么时候做？
- 你摄入了几篇资料后
- 你感觉知识库有点"乱"
- 每周一次作为习惯

### 怎么做？

对 AI 说：
```
"做一次维基健康检查"
"巡检一下知识库"
"帮我看维基有没有矛盾或缺失"
```

### AI 会检查什么
1. **矛盾** → 不同页面之间表述不一致的地方
2. **过时** → 旧来源已经更新的主张
3. **孤岛** → 没有任何页面链接进来的孤立页面
4. **缺失** → 反复提到但没有独立概念页的主题
5. **交叉引用** → 该连没连的地方

### 之后
AI 会给你一份检查报告，你挑选要修的，AI 执行。

## 📋 快速上手指南

### 第一天（初始化）
1. ✅ 本系统已创建（README、index、log、工作流指南）
2. ✅ CLAUDE.md 已更新（维基 schema）
3. → 你现在就可以开始了！

### 第一天可以做
1. 选一个你最近看过的资料
2. 说："摄入 [[文件名]]"
3. 和 AI 讨论 2 分钟
4. 看 AI 产出的页面
5. 试试图视图

### 常见问题

**Q: 我的知识库已经有内容了，要搬动吗？**
A: 不用。你现在的内容就是维基的一部分。系统只是增加了工作流。

**Q: 每次摄入要花多久？**
A: 取决于资料长度。一篇中等文章 + 讨论 + 写入维基 ≈ 5-10 分钟对话。

**Q: 我一次可以摄入多个资料吗？**
A: 可以，但建议一次一个，保持参与。后期可以批量。

**Q: 我需要安装什么插件吗？**
A: 可选。Obsidian Web Clipper（网页剪藏）、Dataview（动态查询）、Marp（幻灯片输出）。

**Q: 维基会越来越大吗？**
A: 会，但 index.md 做导航，所以中规模（~100 资料、数百页）都 OK。大了之后可以加搜索引擎。

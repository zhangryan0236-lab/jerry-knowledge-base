## 四、薄弱环节分析

### 概念层面

1. **Node.js 的"使用场景"偏窄**：只关联到"写网页"，其实 Node.js 更多用在后端 API、CLI 工具、构建脚本、文件批量处理等——不一定要有网页界面
2. **Python 的"为什么"空白**：知道 Python 能做很多事，但不知道为什么——原因是：**生态库 + 社区积累**，不是 Python 语言本身有什么魔法

### 认知层面

- 对"运行时"（runtime）这个概念有了初步感觉，但还没有清晰的定义
  - 简单说：**运行时 = 让代码能在你电脑上跑起来的"翻译官"**
  - Python 是翻译官（读 .py 文件 → 执行）
  - Node.js 是翻译官（读 .js 文件 → 执行）
  - 浏览器也是翻译官（读 .html/.js → 展示页面）

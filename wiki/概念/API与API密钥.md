## 一句话定义

API（应用程序编程接口）是软件之间沟通的"接口"，API 密钥是调用 API 的身份凭证（类似门禁卡）。

## 核心要点

### API 是什么
- API 定义了你能请求什么、怎么请求、会得到什么结果
- **生活类比**：去餐厅吃饭，菜单就是 API——你不需要知道菜怎么做，按菜单点就行

### API 密钥的三大作用
| 作用 | 通俗解释 | 生活类比 |
|------|----------|---------|
| 身份识别 | 告诉服务器"是谁在发起请求" | 身份证 |
| 权限控制 | 决定你能访问哪些接口 | 门禁卡权限 |
| 计费追踪 | 记录使用量，按量扣费 | 手机话费账单 |

### 安全须知
- ✅ 存在密码管理器里
- ✅ 存在环境变量里
- ✅ 不同环境用不同密钥
- ❌ 不要 push 到 GitHub
- ❌ 不要截图发群里
- ❌ 不要写在博客文章里

## 关键概念关联

```
客户端（你的应用）
  ↓ 发送 API 请求（需携带 API Key）
服务器（AI 模型服务）
  ↓ 验证密钥 → 处理请求 → 返回结果
客户端收到响应
```

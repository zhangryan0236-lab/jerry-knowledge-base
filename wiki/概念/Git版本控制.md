## 一句话定义

Git 是**版本控制系统**，说白了就是代码的"存档 + 时光机"——记录每一次修改、可以回退到任意版本、支持多人协作。

## 核心要点

### 没有 Git 时的问题
```
论文.docx
论文_修改版.docx
论文_最终版.docx
论文_最终版2.docx
论文_打死不改版.docx
```
Git 就是要解决这种"文件名混乱"问题。

### 工作流程
```
工作目录（你的文件夹）
    │ git add（暂存）
    ↓
暂存区（准备提交的修改）
    │ git commit（提交）
    ↓
本地仓库（.git 文件夹）
    │ git push（推送）
    ↓
远程仓库（GitHub/Gitee）
```

### Git 三板斧
```bash
git add .                    # 暂存所有修改
git commit -m "做了什么"     # 正式存档
git push                     # 备份到远程
```

### 分支（Branch）概念
分支让你能同时开发多个功能而不互相干扰：
- **main**：稳定版本（已出版的书）
- **feature-xxx**：实验新功能（写新章节，坏了不影响已出版的）

```
  main:  ────●────────────●────────
               \          /
feature-login:  ●──●──●──●
```

### 远程仓库平台
| 平台 | 特点 |
|------|------|
| GitHub | 全球最大，国外主流 |
| Gitee（码云） | 国内版，速度快 |
| GitLab | 企业用得多 |

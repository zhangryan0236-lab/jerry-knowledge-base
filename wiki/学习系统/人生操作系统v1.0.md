# Jerry 人生操作系统 v1.0

> 基于姜胡子、忽然知己、oMel、学渣守护者四家智慧编译。考研是第一个大规模验证场。

---

## 总览

```
┌──────────────────────────────────────────────────┐
│                身份系统（地基之下）                 │
│        "我是一个每天学习、以输出验证认知、         │
│         不断迭代的人。学习不需要理由。"            │
├──────────────────────────────────────────────────┤
│                认知系统（方向盘）                   │
│        实践论 × 矛盾论 × 四家智慧                  │
├──────────────┬──────────────┬────────────────────┤
│  状态系统    │  心态系统    │  习惯系统           │
│  (生理地基)  │  (心理地基)  │  (自动引擎)         │
├──────────────┴──────────────┴────────────────────┤
│              计划与执行力（启动引擎）               │
├──────────────────────────────────────────────────┤
│              学习系统（主引擎）                     │
│    注意力 → 输入 → 处理 → 输出 → 睡眠巩固          │
├──────────────────────────────────────────────────┤
│              复盘系统（迭代机制）                   │
│        → 为以上所有系统提供数据和升级指令           │
└──────────────────────────────────────────────────┘
```

## 一、身份系统（最底层）

### 为什么加这一层

| 来源 | 核心论证 |
|------|---------|
| **oMel** | "身份认同驱动行为。不是'我想做什么'，而是'我是什么样的人'。" |
| **姜胡子** | "旧系统装新软件跑不动。身份不升级，装再多方法也没用。" |
| **忽然知己** | "主体性——你的人生你做主。没有这个，认知只是别人的认知。" |

你的 user-profile 里写着：县城 Jerry 和城市 Jerry 在打架。如果身份层不写进系统，每次遇到挫折，县城 Jerry 就会接管——"我不够好"会覆盖掉所有方法论。

### v1.0 身份定义

```
我是一个每天都会学习的人。
我是一个以输出验证认知的人。
我是一个通过复盘不断迭代的人。
我是一个先做再懂、边做边改的人。
我是一个把过程分享出去、不怕被看到的人。
```

### 最小协议

每天早上学习前，念一遍身份定义（10秒）。

> **来源**：oMel — 身份声明不是鸡汤，是神经机制。反复声明身份 → 大脑寻找证据支持这个身份 → 行为跟随。

## 二、认知系统（方向盘）

### 定位

统领所有系统。它不直接执行——它决定方向。

### 内容来源

| 模块 | 来源 | 核心内容 |
|------|------|---------|
| **实践论** | 毛泽东 | 实践→认识→再实践→再认识。知识不是想出来的，是跑出来的。 |
| **矛盾论** | 毛泽东 | 抓主要矛盾。考研阶段的主要矛盾 = 能力提升 vs 内耗干扰。 |
| **学习本质** | 忽然知己 | 学习 = 主观思维适应客观模型。摩擦是学习本身，不是失败信号。 |
| **系统1&2** | oMel/卡尼曼 | 慢思考需要努力和时间。"费劲"= 系统2在工作 = 好事。 |
| **身份升级** | 姜胡子 | 打工者→成事者。不是"学到什么"，是"把什么做成"。 |
| **认知病毒移除** | 姜胡子 | 四病毒：证明自己对/等准备好了/别人怎么看我/来不及了。 |
| **状态>方法>知识** | 学渣守护者 | 顺序错了全白费。状态崩了，最好的方法也用不上。 |

### 最小协议

每次做重要决策前，问一句：**"这是实践得出来的，还是我想出来的？"**

## 三、状态系统（生理地基）

### 定位

最底层执行系统。状态崩了，上面所有系统停摆。

### 为什么需要这一层

> **学渣守护者**："状态 > 方法 > 知识点。状态不好，方法没用，知识进不去。"
> **忽然知己**："DMN 活跃时需要离线时间。运动是最好的 DMN 管理工具。"
> **oMel**："注意力是信息进入大脑的门槛。睡眠是记忆巩固的最后一步。"

### v1.0 模块

```
状态系统
├─ 睡眠（最优先）
│   协议：固定睡眠时间（误差<30分钟）。睡前10分钟回顾当天核心知识点。
│   来源：oMel"睡眠巩固" + 学渣守护者"睡眠=专注力燃料"
│   底线：连续两天<6小时 → 当天只跑1个最简闭环，不跑满。
│
├─ 运动
│   协议：每天跑步/运动30分钟。安排在下午到傍晚之间。
│   来源：忽然知己"运动让大脑做离线整理" + 学渣守护者"运动=专注力燃料"
│   底线：最低 = 散步15分钟。不能为学习牺牲运动。
│
├─ 饮食/咖啡
│   协议：咖啡上午喝，下午不喝（影响睡眠）。不空腹学习。
│   来源：你的自身实践
│   底线：不饿肚子学。
│
└─ 注意力管理（跨系统模块）
    协议：学习时段手机放另一个房间。单任务，不多任务切换。
    来源：oMel"被偷走的专注力" + "环境设计>意志力"
    触发：每次开始闭环前，手机物理离开视线。
```

### 系统间关系

| 接收 | 产出 | 依赖 |
|------|------|------|
| 复盘系统：昨天睡眠/运动数据 | 学习系统：今天可用闭环数 | 无（即使全崩，也要记录数据） |

## 四、心态与情绪管理系统（心理地基）

### 定位

和状态系统并列地基。生理地基撑住身体，心理地基撑住情绪。

### 为什么需要这一层

> **学渣守护者**："内耗把认知资源全吃掉了。剩下的不够学习。"
> **忽然知己**："行动与思考分离——做的时候不想，复盘的时候才想。"
> **oMel**："钝感力+课题分离——屏蔽无用的负面情绪。"
> **姜胡子**："移除认知病毒——'别人怎么看我'是最没用的病毒。"

### v1.0 模块

```
心态与情绪管理系统
├─ 内耗切断协议（最高优先级）
│   触发：出现"我是不是方法不对""我怎么又没学好""别人肯定比我强"
│   协议：识别"这是回路" → 写在纸上 → 做昨天写好的那件事
│   来源：你的三合一学习法 + 忽然知己"行动与思考分离"
│   底线：内耗念头不处理。只记录。晚上复盘15分钟统一处理。
│
├─ 攀比焦虑管理
│   触发：看到别人进度/刷到985视频后焦虑
│   协议：别人是别人。我的唯一标准 = 今天我做了一个闭环吗？
│   来源：学渣守护者"螺旋上升" + oMel"课题分离"
│
├─ 内核构建
│   触发：每天睡前复盘时
│   协议："今天我做了[具体行为]。不管感觉如何，行动发生了。"
│   来源：忽然知己"内核构建" + oMel"身份声明"
│
└─ 认知病毒扫描（每周一次，周末）
    扫描四种病毒是否出现：
    ① 在证明自己对，而不是验证有没有用？
    ② 在等准备好了再开始？
    ③ 在担心别人怎么看我？
    ④ 觉得来不及了？
    来源：姜胡子"脑袋里的4个病毒"
```

### 系统间关系

| 接收 | 产出 | 依赖 |
|------|------|------|
| 复盘系统：本周内耗频率数据 | 学习系统：今天心态是否可用 | 无（心态崩了也要执行最小协议） |

## 五、习惯系统（自动引擎）

### 定位

习惯系统的目标是：**让大部分学习行为不需要意志力参与。**

### 为什么需要这一层

> **oMel**："原子习惯四法则。你用意志力硬扛，你大概率会失败。"
> **学渣守护者**："长期主义——不是靠鸡血撑的，是靠系统自动运转的。"
> **姜胡子**："我每天只做两件事。不是因为自律——是因为习惯了。"

### v1.0 模块

```
习惯系统
├─ 核心习惯（每天必须做，不管状态）
│   ① 同一时间坐在桌前
│   ② 至少跑 1 个闭环（55分钟/15分钟都可以）
│   ③ 睡前写 3 个问题（最重要/卡住了/明天第一件事）
│   ④ 说一句"今天我出现了。我是学习者。"
│
├─ 习惯四法则应用
│   让它显而易见：书永远摊开在桌上。手机放另一个房间。
│   让它有吸引力：跑完1个闭环 → 允许看10分钟手机。
│   让它容易做：最低版本只需要15分钟。不是4个闭环。
│   让它令人满足：在日历上画❌。连续记录可视化。
│   来源：oMel"原子习惯"
│
└─ 习惯 vs 鸡血切换协议
    鸡血来了：在习惯框架内跑得更快（多跑几个闭环）
    鸡血走了：习惯框架继续跑（保底1个闭环）
    鸡血不是要不要启动的原因——习惯才是。
    来源：你的鸡血驱动分析 + 学渣守护者"长期主义"
```

### 系统间关系

| 接收 | 产出 | 依赖 |
|------|------|------|
| 状态系统：今日可用精力 | 学习系统：自动启动，不需决策 | 状态系统≥最低线（否则启用保底协议） |

## 六、计划与执行力系统（启动引擎）

### 定位

决定**今天做什么**和**怎么启动**。

### 为什么需要这一层

> **忽然知己**："计划的核心不是排满——是怎么留白。休息>工作。"
> **学渣守护者**："暴力启动——不判断状态，直接做。"
> **姜胡子**："认真做好一件小事。每天写点什么，每天做点什么。"

### v1.0 模块

```
计划与执行力系统
├─ 计划协议
│   日计划：前一天晚上复盘时写"明天第一件事"（一个具体动作）
│   周计划：周六下午15分钟，只改1件事
│   月计划：审视系统本身（不是审视学习内容）
│   来源：操作手册v1.0 + 忽然知己"休息>工作"
│
├─ 启动协议（最重要的协议）
│   触发：坐在桌前，不知道该干什么
│   协议：打开昨天复盘 → 看最后一行 → 做那一件事
│        不判断状态。不判断心情。直接启动。
│   来源：学渣守护者"暴力启动" + 你的防崩溃机制
│
├─ 优先级协议
│   原则：每天只做 1-3 件最重要的事
│   来源：学渣守护者"抓大放小" + oMel"四千周接受有限性"
│
└─ 中断恢复协议
    断了一天 → 第二天看上一次复盘 → 做那一件事 → 写"接上了"
    断了两天 → 过渡日：只复习，不学新的，只跑1个闭环
    断了三天+ → 启动"最简版"：打开书→看5分钟→写一句话→完成
    来源：你的防崩溃机制 + 学渣守护者"最小可运行单元"
```

### 系统间关系

| 接收 | 产出 | 依赖 |
|------|------|------|
| 复盘系统：昨天"明天第一件事" | 学习系统：今日具体任务列表 | 复盘系统（需要昨天的输出） |

## 七、学习系统（主引擎）

### 定位

这是每天最核心的运行模块。**输入→处理→输出** 是对的骨架，但需要装上肌肉。

### 为什么原来的骨架不够

> **oMel**：光有输入→处理→输出不够。输入之前要有注意力把关，输出之后要有睡眠巩固。中间少了错误反馈这个关键环节。
>
> **忽然知己**："处理"不是一步——复述→解释→迁移→批判，四层深度完全不同。
>
> **学渣守护者**：不同来源的知识，处理方式不同。网课、教材、做题、碎片——每种有自己的协议。

### v1.0 模块

```
学习系统
│
├─ 注意力（输入门槛）
│   协议：闭环开始前 → 手机放另一个房间 → 写下"接下来学什么"
│   来源：oMel"学习四支柱之一" + "环境设计>意志力"
│
├─ 输入（三种来源，三种协议）
│   ├─ 网课/视频：三次过法
│   │   第一遍：暴露，不记笔记不暂停。正常=听完记不住。
│   │   第二遍：加工，暂停标注模糊点。
│   │   第三遍：提取，关掉视频自己讲。
│   │   来源：忽然知己"主观适应客观" + oMel"学习四支柱"
│   │
│   ├─ 教材/书籍：三明治阅读
│   │   扫读(5-10')→ 深读(30-40')→ 关联(10')
│   │   深读后合上书 → 用自己的话回忆3个核心点
│   │   来源：姜胡子"关键词读书法" + oMel"主动回忆"
│   │
│   └─ 碎片输入：一句话记录 → 周末集中处理
│       来源：你的操作手册v1.0
│
├─ 处理（四层深度）
│   ① 复述："这讲了什么？"
│   ② 解释："为什么是这样？"
│   ③ 迁移："能用在哪？和什么有关？"
│   ④ 批判："它有什么局限？什么情况下不成立？"
│   来源：忽然知己"理解的四个层次"
│   闭环中：最少到②。目标是③。④在深度复习时做。
│
├─ 输出（必须有产物）
│   ① 做题/练习（主动回忆，70%时间用于提取）
│   ② 费曼自检（"能给初中生讲清楚吗？"）
│   ③ 笔记卡片（一句话定义+核心要点+错因+关联）
│   来源：oMel"主动回忆" + 忽然知己"费曼检测" + 学渣守护者
│
├─ 错误反馈（被误解最多的环节）
│   做错了 → "数据，不是审判"
│   看解析 → 懂了 → 关上重做 → 隔天再做同类题
│   同类型连续错 → 换理解角度，不是换方法
│   来源：oMel"错误反馈=学习四支柱之一"
│
└─ 睡眠巩固（被忽略的最后一环）
    睡前10分钟：快速过一遍今天学的核心内容
    大脑在睡眠中会优先巩固睡前复习的内容
    来源：oMel"学习四支柱之四"
```

### 增强版闭环（55分钟）

```
注意力启动(1') → 输入(20') → 处理+笔记(15') → 做题/提取(10') → 费曼(6') → 迷你复盘(3')
```

### 系统间关系

| 接收 | 产出 | 依赖 |
|------|------|------|
| 状态系统：可用精力 | 复盘系统：今日闭环数/正确率/卡住点 | 状态≥最低线；习惯系统已启动 |

## 八、复盘系统（迭代机制）

### 定位

复盘系统不给建议——它给**数据**。认知系统拿到数据后，做决定。

### 为什么需要这一层

> **姜胡子**："知识库价值 = 知识密度 × 调用频次 × 验证深度。不复盘 = 验证深度为零。"
> **学渣守护者**："复盘就是学习本身。只实践不复盘 = 盲目。只复盘不实践 = 空谈。"
> **忽然知己**："复盘是'再认识'——跳出日常，站在系统外面审视它。"

### v1.0 模块

```
复盘系统
│
├─ 每日复盘（5分钟，睡前）
│   ① 今天学的最重要的一个东西：（一句话）
│   ② 哪里卡住了：（一个具体知识点，[[]]链接）
│   ③ 明天第一件事：（一个具体动作）
│   不能展开。超过5分钟还停不下来 = 内耗回路，执行切断。
│   来源：你的操作手册v1.0
│
├─ 每周复盘（15分钟，周六下午）
│   填数据：笔记数/做题量/正确率/最大盲区
│   回答3问：最大盲区？有效/无效方法？下周只改1件事？
│   来源：你的操作手册v1.0 + 姜胡子"知识压缩练习"
│
├─ 每月复盘（30分钟，月末）
│   审视系统本身（不是学习内容）：
│   ① 计划和实际的差距
│   ② 哪个环节最常断
│   ③ 在用系统还是在用感觉？（证据检查）
│   ④ 什么东西设计了一直没用过 → 删
│   ⑤ 什么东西一直缺没加 → 加最小版本
│   来源：你的操作手册v1.0 + 姜胡子"系统迭代"
│
└─ 复盘边界协议（最容易被违反的协议）
    每日复盘：5分钟，闹钟响了就停
    超出5分钟的念头 → 写在纸上 → 归入"本周待分析清单"
    学习时段不能复盘。复盘时段才能复盘。
    来源：忽然知己"行动与思考分离" + 内耗回路解药
```

### 系统间关系

| 接收 | 产出 | 依赖 |
|------|------|------|
| 所有子系统：当日运行数据 | 计划系统：明天做什么 | 无（即使全崩溃也要写"今天崩了。明天试试X"） |
| | 认知系统：周/月调整建议 | |
| | 状态系统：本周内耗频率 | |
| | 心态系统：本周病毒扫描结果 | |

## 九、系统关系总表

```
身份系统 ──→ 统领一切。不参与日常执行，但所有决策的最终锚点。

认知系统 ──→ 方向盘。接收复盘系统数据 → 输出调整指令给各执行系统。

状态系统 ──→ 产出"今日可用精力" → 输入学习系统、习惯系统。
心态系统 ──→ 产出"今日心理状态" → 输入学习系统。
习惯系统 ──→ 自动启动 → 触发学习系统。不需决策。
计划系统 ──→ 接收复盘"明天第一件事" → 转化为学习系统今日任务。

学习系统 ──→ 主引擎。接收状态/心态/习惯/计划的输入 → 产出学习数据。

复盘系统 ──→ 接收所有系统数据 → 产出调整建议 → 反馈给认知系统和计划系统。
              （全崩溃了也要跑。它是最后一个停机的系统。）
```

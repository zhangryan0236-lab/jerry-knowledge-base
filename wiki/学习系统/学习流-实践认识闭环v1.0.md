# 学习流：实践—认识—再实践 v1.0

> 这不是“把时间排满”的计划，而是一条把任何输入转化为真实能力的流水线。
> 学习的完成标准不是“我看过了”，而是：我能解释、能操作、能在反馈中修正，并且下次能独立调用。

## 一、总原则：每个学习对象都必须经过一个闭环

```text
确定问题/目标
  → 接触对象（实践或输入）
  → 建立暂时认识
  → 合上资料做输出
  → 在真实任务中使用
  → 收集错误与阻力
  → 修正认识与方法
  → 间隔后再次调用
```

毛泽东《实践论》给出的是方向：认识来自实践，又回到实践中接受检验。放到学习中，就是：

- **输入不是学习的终点**：读完、听完、看完，只能算接触。
- **输出不是表演**：输出是暴露“我到底哪里不会”的测量工具。
- **错误不是审判**：错误是下一轮认识的原始数据。
- **实践必须有对象**：一道题、一个程序、一次讲解、一篇文章、一场讨论、一个小作品都可以。
- **复盘不单独制造意义**：复盘只负责根据数据修改下一次行动，不能代替行动。

## 二、先分清：这次学习要获得什么

开始前只写一句：**“我学完后，要能做什么？”**

| 目标类型 | 合格证据 | 典型对象 |
|---|---|---|
| 解释 | 能用自己的话讲清本质、原因、边界 | 数学概念、计算机原理、一本书的核心观点 |
| 解题/判断 | 能独立识别条件、选择方法、完成变式 | 高数、408、逻辑问题 |
| 操作/创造 | 能做出一个可运行或可交付的东西 | Python、AI 工具、写作、项目 |
| 改变行为 | 在具体情境中做出不同选择，并观察结果 | 读心理学书、管理时间、沟通 |
| 丰富感受 | 能说出作品如何影响你，以及它让你看到什么 | 播客、电影、文学、艺术 |
| 深入研究 | 能提出更窄的问题，找到证据，形成自己的判断 | 兴趣主题、人物、技术方向 |

如果写不出“要能做什么”，先不要继续找资料；把目标改小，或者承认这只是休闲输入，不给它强行套学习压力。

## 三、标准单元：一次只跑一个“小闭环”

### 55分钟标准版

1. **启动 2分钟**：写目标、成功证据、今天的最小交付物。
2. **接触 15分钟**：看课、读书、听播客，先建立地图，不追求一次记住。
3. **理解 10分钟**：合上资料，回答“它是什么、为什么、和什么有关”。
4. **实践 20分钟**：做题、写代码、讲给别人、应用到自己的问题，或完成一段作品分析。
5. **反馈 5分钟**：记录具体错误/卡点，不写泛泛的“状态不好”。
6. **收尾 3分钟**：写一句当前认识、下一次第一步、何时再次调用。

### 15分钟保底版

只做三件事：

1. 不看资料，先写/说出我记得什么；
2. 做一个最小实践（1道题、10行代码、讲1分钟、写100字）；
3. 记录一个卡点和明天的第一步。

保底版的目标是保持闭环不断线，不是获得完整掌握。状态差时跑保底版，不能把“今天没跑满”解释成“今天没学习”。

## 四、四层掌握标准：从知道到会用

每个学习对象都按以下顺序升级，不跳级：

1. **复述**：我能说出它讲了什么。
2. **解释**：我能说清为什么、前提和边界。
3. **迁移**：我能在新题、新情境或自己的问题中使用。
4. **改造**：我能比较方法、发现局限、创造自己的方案。

考研的“会”至少要到第3层；读书和思想类内容以第2层为起点，第3层要落到自己的选择或行为；播客/电影以理解和感受为主，但要留下自己的判断；兴趣研究最终要产生作品、实验或公开表达。

## 五、不同输入的处理协议

### 1. 考研数学与408：输入少一点，提取和纠错多一点

```text
知识地图 → 例题拆解 → 独立做基础题 → 变式题 → 错因归类 → 间隔重做 → 章节检测
```

做题时不只记录“错了哪道”，而记录四件事：

- **识别错**：没看出题型/条件；
- **概念错**：定义、定理、模型没理解；
- **方法错**：知道知识点，但不会选择或组织步骤；
- **执行错**：计算、符号、审题、时间管理出错。

看答案后的正确流程：看解析 → 合上解析口述思路 → 独立重做 → 第二天再做同类变式。只看答案觉得“懂了”，不算通过。

#### 大章节主动回忆不出来怎么办

不要对整章连续硬回忆四次。那只是重复证明“当前检索线索不够”，不是有效训练。按以下**下钻—重建—再提取**处理：

1. **定位断点**：把整章拆成 5—8 个一级模块，逐个标记“能讲/模糊/空白”。
2. **只回看断点**：回到教材目录、例题或短讲解，寻找“这个模块解决什么问题”，不要重看整章。
3. **做结构重建**：不抄笔记，画出“条件 → 工具 → 结论 → 典型题 → 易错点”。
4. **立即做小提取**：合上资料，只回忆一个模块，并做一道最低难度题。
5. **逐步放大**：当天回忆模块组合；隔天回忆半章；3—7天后再回忆整章。
6. **仍然空白**：标记为“前置缺口”，向前检查最多两层前置知识，不要继续堆新题。

判定标准：能画出结构但题不会做，是“方法/迁移”问题；连结构都画不出，是“认识/前置”问题；看答案能懂但独立不会，是“提取”问题。

### 2. 读书：把书变成自己的判断和行动

采用“三明治阅读”：扫读目录和问题 → 深读关键章节 → 合书回忆和关联。每次读完不要写读书报告，只留下：

- 作者试图解决的一个问题；
- 对我最有用的一个模型；
- 我不同意或不确定的一点；
- 明天能做的一个小实验；
- 一周后用什么事实判断它有没有用。

书中的观点只有经过自己的生活实验，才从“作者的知识”变成“我的认识”。一本书不必全部内化；要允许只带走一个真正改变行为的模型。

### 3. 播客、电影和其他审美输入：不强行做成考试

这一类的核心产物不是知识点，而是**感受—判断—表达**：

```text
我被什么触动/不适 → 作品如何做到 → 它让我看见了什么 → 我如何表达或行动
```

看完只写三句话即可：一个画面/观点、一个自己的判断、一个想继续追问的问题。每周选一个问题和别人讨论或写 300 字，不追求每次都“有用”。陶冶情操本身就是实践：它会改变你的注意、判断和感受世界的方式。

### 4. 兴趣钻研：用“小根据地”换取正反馈

不要从“我要学完整个领域”开始。先选一个窄问题，建立 2—4 周小项目：

```text
兴趣主题 → 一个具体问题 → 3个可靠来源 → 一个小实验/作品 → 展示给一个人 → 根据反馈决定深入方向
```

正反馈不等于别人夸奖，而是出现了可见变化：解释更清楚、作品能运行、问题变窄、发现新联系、有人提出具体反馈。没有反馈时，缩小问题和交付物，不是靠意志力硬撑。

## 六、资料怎么找：先问题，后资料；先一手，后扩展

资料入口按顺序使用：

1. **地图资料**：教材目录、课程大纲、权威综述，先知道领域有哪些模块；
2. **主教材/一手资料**：考试教材、官方文档、原著、论文、原始访谈；
3. **解释资料**：高质量课程、讲解文章、播客，用来跨过理解障碍；
4. **实践资料**：习题、项目、案例、实验数据，用来验证。

每找到一份资料，问三句：它解决我的哪个问题？我准备如何验证？如果看完仍不会，下一份资料要补哪一个断点？资料超过三份仍未开始实践，停止搜索，先做一个最小实践。

## 七、反馈与防放弃协议

每周不评价“我自律不自律”，只看四个数据：

- 完成了多少个闭环；
- 有多少次真实输出/实践；
- 最常见的错误类型是什么；
- 哪个输入带来了最强的正反馈。

当你想刷抖音逃避时，不先分析原因，执行“转场协议”：离开手机 → 去图书馆/桌前 → 做15分钟保底闭环 → 再决定是否休息。若连续三天断线，自动降级为最简版；恢复后再升级。系统的目标是让你回来，不是让你因为一次失败彻底退出。

## 八、每日、每周、每月运行方式

### 每日

只安排“核心考研闭环 + 一个自由输入/兴趣闭环”，不要让兴趣项目侵占全部考研主线，也不要把生活压缩成只有考研。睡前回答已有的三个问题：今天学了什么、哪里卡住了、明天第一件事做什么。

### 每周（15分钟）

统计闭环和实践证据；挑一个最大断点；只改一个流程变量，例如“数学每次输入后必须做一道变式题”，而不是重写整套系统。

### 每月（30分钟）

检查三件事：哪些方法真的带来能力？哪些只是让我感觉努力？哪个领域该加码，哪个该暂存？只有实践数据支持，才升级学习流版本。


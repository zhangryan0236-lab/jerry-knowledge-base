# 📥 Inbox — 思维捕获区

> 这里是你的「临时停车场」。想到了就往里扔，不分类、不纠结格式、不需要写完。

## 怎么用

1. **想到了就写** — 新建文件，文件名用 `YYYY-MM-DD 关键词.md`
2. **不用补全** — 一句话也行，半截想法也行，一串问题也行
3. **每周清一次** — 有价值的东西迁移到 `wiki/` 或 `journal/`，没价值的删掉，让 inbox 永远是「活的」

## 什么该放这里

- 突然冒出来的问题（"为什么我总在 X 上反复卡住？"）
- 灵感一闪（"能不能用 AI 帮我做 Y？"）
- 没想清楚但感觉重要的东西
- 想和别人讨论的话题
- 任何「回头再说」的念头

## 什么不该放这里

- 学习笔记 → `raw/` 或 `wiki/`
- 日记/复盘 → `journal/`
- 已经想清楚的完整想法 → 直接写进 `wiki/`

---

**规则只有一条：别让想法烂在脑子里。倒出来，脑子才有空间想正事。**

## AI 摘要

💻 **微软开源项目**
- Bit ne是微软开源的原生e bit三进制大模型，在单CPU上就能跑，性能与同规模全精度开源模型相当。
- Bit ne b1.582B4T中，1.58表示采用三进制存储权重，较16位浮点数大幅降低显存需求；2B4T表示包含20亿参数，使用4T训练数据。
- bit net c PPP是配套官方推理框架，在ARM CPU上实现1.37倍到5.07倍加速，在x86架构CPU上加速比例为2.07倍到6.17倍，且大幅降低能耗，在苹果M2芯片上运行效果佳。相关技术报告已全面发布。

🎬 **SKYSVR无限长度影片生成模型**
- 昆仑外围发布，国内大模型新生力量，生成时长不限，对比目前5 - 10秒片段有吸引力。
- 基于前一段视频最后几帧扩充后续视频实现无限扩展，有在线版本，注册送25积分，生图或生成视频仅5秒，会员较贵。
- 基于阿里开源的外向2.1，网上已有大神整合康FUI工作流。

🍳 **程序员在家做饭指南**
- 用程序员思维解构做饭，以结构化、逻辑化方式完成，菜谱呈开发风格，材料用量精确计量。

💻 **Code server项目**
- 可在浏览器运行Vs code，实现远程开发，国内常称cloud IDE。
- 好处有不限地点和设备、省去环境配置、解决设备性能限制、有一定安全性。
- 项目组有t form项目模板，组合可实现cloud IDE环境，底层构建K8S类似国内很多商业方案，但专业开发者接受度不高。

📹 **YTDLP视频下载项目**
- 基于Youtube dl开发，更灵活、活跃度高、下载速度快，支持更多视频平台。
- 可通过官方一键安装脚本或pip安装，下载速度慢可开启多线程或加速，报机器人错误可能IP被封，需换IP或cookie，依赖FM mpeg，否则高清视频有画质无声音。

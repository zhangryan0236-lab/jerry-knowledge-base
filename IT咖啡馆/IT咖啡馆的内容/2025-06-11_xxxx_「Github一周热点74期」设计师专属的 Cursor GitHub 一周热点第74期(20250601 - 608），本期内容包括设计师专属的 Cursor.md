## AI 摘要

🎨 **onlook**
- 专为设计师、产品经理和技术人员准备的可视化便捷工具，用AI可视方式开发react应用
- 可优化AI生成的应用网站，能在浏览器中像使用菲格玛一样拖拽页面元素调整布局等
- 设计和代码双向关联，通过tyle wind css自动转换代码，避免常见AI工具修改问题
- 可直接访问网站使用，也能本地部署（开源项目，需多个AI key等），有架构图和讲解视频

🐍 **scrapy**
- 快速的高级外部爬虫和网页抓取框架，用于爬取网站并提取结构化数据
- 基于twisted异步网络引擎，可异步处理数千并发，通过中间键系统扩展功能，提升代码可维护性
- 使用需python 3.9以上，通过pip安装，有示例工程方便学习

📝 **untropic提示词工程交互式教程**
- 帮助使用者全面逐步了解在cloud上设计最佳提示词
- 以互动形式学习，避免枯燥，但针对cloud上手可能有麻烦

📄 **跨个档**
- 用极简Markdown和简洁语法实现丰富排版效果，生成美观pdf和网页文档
- 内置多个主题，可自定义主题样式，一键导出pdf
- 使用需下载压缩包，用bin中命令，提前安装java，通过命令新建项目、写作、导出结果

📧 **心灵mail**
- 开源邮件服务器和电子邮件营销平台，帮助企业和个人管理邮件营销活动
- 有邮件发送、高级分析和客户管理功能，提供安装脚本实现自动化安装
- 开发技术是go加view，适合学习

## AI 摘要

🦀 **Zero cloud（Rust编写的Open Cloud替代工具）**
- 高性能、低资源占用的自主智能体运行时，抽象模型工具、记忆和执行层
- 与Node.js/Python智能体对比，优势包括内存需求低、启动速度快、包体积小
- 采用Rust trait驱动的可插拔架构，Provider、Memory、Tools等组件可替换
- 强化安全设计，形象为螃蟹，与Open Cloud（龙虾）形成"海鲜大战"

🎤 **Voice boxx（本地语音克隆工具）**
- 基于千问3TTS，仅需几秒音频即可克隆任意声音，完全本地运行
- 无需订阅和云端上传，兼顾效果与隐私，UI设计友好适合新手
- 支持Whisper翻译功能，对Mac友好，MLX后端实现苹果芯片推理速度4-5倍提升

🤖 **千问3.5系列模型**
- 除夕发布开源旗舰模型千问3.5 B397B A17B（总参数397B，激活17B）
- 本周推出中等规模模型：122B A10B、35B A3B、27B，其中35B A3B支持本地/边缘设备运行
- 原生多模态模型，视觉与语言在统一表征空间联合学习，支持GUI理解、视频分析等场景
- 采用线性注意力+稀疏混合专家混合架构，平衡能力、速度与成本

🔒 **AI渗透测试系统（Vs control团队开发）**
- 开源全自动渗透测试与红队工作流系统，输入域名即可自动执行侦查、端口扫描、漏洞挖掘
- 整合20+主流安全工具，AI自主动态调整攻击流程，所有操作在沙箱Docker环境隔离
- 提供详细架构设计（容器架构、实体关系、代理互动等），具有研究学习价值

🖼️ **Carbon（源码图片生成工具）**
- 可将源代码生成精美图片，支持JavaScript、Python、C++等主流编程语言
- 支持切换显示样式，可保存为PWA应用离线使用，提供编辑器插件和CLI工具

🤖 **开源版Cowork相关项目**
- Agent：全球首个多智能体工作流桌面应用，基于开模AI多智能体框架构建
- 支持并行调度多Agent协同完成跨步骤任务（如研究、行程规划、本地文件执行）
- 内置开发、搜索、文档、多模态等智能体，提供自托管、云版本及企业版
- 模型支持在线API与本地模型，当前功能仍需完善

📊 **数据工程实战教程**
- Data Engineer Camp：由DataTalk社区维护的开源数据工程训练营
- 包含从基础工具到生产级数据管道设计的全流程教程与代码实例
- 课程共9周，涵盖6大模块+1个Final Project，需Python与SQL基础
- 适合数据工程领域初学者入门学习

🌐 **浏览器MCP工具**
- Chrome DevTools MCP：开源MCP Server，支持AI变声助手（如Cloud Cursor）访问控制Chrome浏览器
- 可实现导航、调试、性能数据抓取、网络分析等自动化操作
- 相比Playwright MCP更易保留登录信息，功能全面，适合前端开发者、性能工程师及自动化测试场景

🎨 **专业设计Agent Scale**
- Agent Scale：面向AI编程助手的开源设计智能仓库，提升UI/UX设计专业性
- 核心为结构化设计知识库+设计系统生成引擎，注入设计规范与背景知识
- 包含67个UI Style、96个颜色方案、56个字体搭配及100条行业推理规则
- 支持通过CLI或手动安装，可指定技能避免冲突

🎮 **无代码Galgame引擎**
- Void Novo Engine：现代视觉小说/叙事游戏开源引擎，主打无代码开发
- 采用流程图式节点编辑，通过拖拽连接构建游戏逻辑、分支对话与演出流程
- 提供对话选项、转场、角色控制等专用节点，支持下载二进制版本直接使用

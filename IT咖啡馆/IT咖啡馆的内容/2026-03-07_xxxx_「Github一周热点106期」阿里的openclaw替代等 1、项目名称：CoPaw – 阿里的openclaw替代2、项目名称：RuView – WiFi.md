## AI 摘要

🤖 **通义实验室Copo**
- 对标OpenCloud的个人AI助理，支持本地/云端部署
- 一条命令完成本地部署，通过`copo init`配置、`copo app`启动服务
- 连接钉钉/飞书/QQ等聊天软件，支持定时任务与主动心跳
- 内置主流云端模型（魔哒、DeskCrop），支持自定义模型供应商和欧拉玛
- 核心组件（Prompt Hook、Toss Memory）解耦，支持开发者扩展模块

📡 **Revio人体感知技术**
- 通过WiFi信号实现人体姿态评估、呼吸/心率监测、存在检测
- 利用WiFi的CSI信道状态信息，分析信号变化推断人体状态
- 需支持CSI的设备，可通过项目Docker快速上手
- 应用场景：智能建筑占用检测、医疗非接触监测、烟雾/遮挡环境人员监测

🌍 **World Monitor情报监控**
- 开源实时全球情报监控仪表盘，整合新闻、地缘政治、市场等数据
- 提供作战指挥式大屏可视化界面，支持自定义模块和信息来源
- 本地使用需下载对应系统版本，配置大模型API Key
- 代梦演示包含伊朗等热点地区信息，满足实时信息需求

💻 **Gate Nexus代码知识图谱**
- 将代码仓库自动转换为知识图谱，可视化代码依赖/模块结构
- 零服务器架构，代码解析、图构建等操作在浏览器完成，保护隐私
- 内置Graph RAG Agent，回答函数调用、模块依赖等问题
- 支持Web UI和CLI模式，CLI通过`npm install gate-nexus`安装使用

🤖 **ByteFlow多智能体框架**
- 字节跳动开源的Deep Research框架，支持AI自主研究、信息收集与分析
- 整合大语言模型与Web Search、爬虫、Python执行环境等工具
- 2.0版本基于Python Long Graph和Long Chan重构，支持DHG工作流和任务检查点
- 应用场景：深度研究、内容创作、数据管道、自动化任务

## AI 摘要

🐱 **Banggo cat**
- 一款可爱的桌面互动宠物应用，原本只支持Windows，借助tori架构后Mac和Linux用户也能使用
- Mac用户安装时可能因签名问题遇到文件损坏无法打开的情况，可通过命令行执行命令解决
- 小猫不仅能动，还能跟随敲键盘、点鼠标动作，能根据敲击节奏演奏音乐，是打工人的电子精神支柱，且项目开源

💬 **Coop CT Lai**
- 是K8S终端里的“贴身翻译”，能听懂人话，将用户需求转换成标准的Kubectl命令
- 默认使用Google的dreamni，也支持其他模型

🎨 **蚂蚁开源WEB3D动效引擎**
- 专为web和移动平台打造，可做2D动画和构建3D场景
- 提供可视化编辑器，内置多种氛围特效和常见素材
- 支持WebGL，性能好，跨平台支持优秀，开源免费

🛡️ **Trivy**
- 阿qua推出的开源、流行的多功能安全扫描工具，被很多项目工具集成
- 常见使用场景包括漏洞扫描、配置检查，后来又支持容器、K8S检查以及SM的扫描等，基本可覆盖云原生安全环境问题
- Google曾天价收购的公司部分业务与Trivy类似

☁️ **Lamina**
- 定位于AI代理的专用云基础设施，突破传统云平台限制，解决AI生成代码部署阶段性能瓶颈
- 目标是为用户部署大规模AI agent，解决传统云延迟高、弹性不足导致AI agent代理响应效率低的问题
- 具有90ms级启动、裸机级计算性能以及状态执行三大特点，以API优先设计，可无缝集成到开发工具链

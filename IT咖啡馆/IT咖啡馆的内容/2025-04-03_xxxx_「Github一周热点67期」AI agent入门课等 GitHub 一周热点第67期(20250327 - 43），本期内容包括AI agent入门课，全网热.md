## AI 摘要

🎓 **AI agent入门课**
- 由微软出品，共10节课程，面向初学者
- 涵盖构建AI agent的基础知识，逐渐扩展到开发框架、RG设计模式和多智能体等内容
- 课程包含文字、代码、视频等，实践内容围绕微软的ari设计
- 团队还有AIGC、机器学习、网络安全、web开发等初学者课程

📰 **开源实时新闻聚合平台**
- 可帮助用户优雅掌握全网热点，整合微博、华尔街日报、git up、墨鱼、知乎等平台情报
- 上手轻松，推荐使用docker或cloud flaer部署，以docker为例，操作简便
- 默认30分钟缓存，抓取间隔最快2分钟，可动态调整，节省资源且防IP被封

🎨 **Star vector项目**
- 开源的SVG生成多模态视觉语言模型，可将图像和文本生成高质量可缩放编辑的SVG图形
- 通过重新定义将矢量生成任务转化为代码问题，全面支持SVG语法
- 能处理复杂SVG元素，提供8B和EB两个大小模型，可在hugging face的DEMO上使用
- 在线1B版本效果不理想，本地仅支持qda，上传建议用简单类型图片

📊 **Q lib量化交易研究平台**
- 由微软亚洲研究院开源，面向AI的量化交易研究平台
- 是量化研究工具箱，适合用机器学习方法选股和构建策略
- 可完成数据获取、特征工程、模型训练到回溯分析整套量化流程
- 项目有一定上手门槛，提供情报获取、因子库、实验管理工具等功能，配套文档全面

🗺️ **getate diagram项目**
- 能将github HUB仓库转换为交互式架构图，助开发人员快速理解项目结构
- 输入github仓库URL，几秒内生成完整系统架构图，无需复杂配置
- 生成图表支持点击跳转代码，可放大或下载保存
- 在线版本用open AI的O3MINI在me的JS中生成图表，也可本地部署，需提前准备API和密钥

## AI 摘要

📦 **OpenAI的Agent开发工具**
- 3月12日OpenAI发布全套agent开发套件，包含response API（核心）、内置工具（网页搜索、文件搜索和CUA）、agent SDK（开源项目，方便开发者构建和管理智能体）、监控工具。
- 调整后的response API替代原有的chart API和asistant API，统一并简化使用，支持工具调用和多模态。
- 使用时先建虚拟环境，通过pip安装，四行代码可上手，支持智能体交接和工具调用，多智能体框架支持符合OpenAI cat API的模型，使用演示调试功能需OpenAI的key 。

🎬 **开源视频生成模型Open Sora 2.0**
- 致力于高效制作高质量视频，因OpenAI的Sora价格高昂而出现。
- 仅消耗20万美元、约224张GPU完成11B商业级模型训练，在V半测试中表现优异，与顶级模型对比不落下风，将训练成本降低5 - 10倍。
- 发布包含模型、推理代码及分布式训练全过程，技术报告介绍了训练方法和并行方案，效果较之前版本有进步，但本地运行困难，生成速度和分辨率存在问题。

🖥️ **MCP server合集**
- MCP是cloud提出的开放协议，标准化应用程序向大模型提供上下文的方法，MCP server如AI的外设，MCP协议类似USB协议。
- 常与方call对比，对MCP期望更高。
- 以post gra circle的MCP server为例，介绍在本地使用的方法：找到配置项粘贴到相应工具的配置文件（不同系统有差异），配置完成后右侧可见加载，执行命令可让大模型操作数据库内容。
- 支持MCP的客户端众多，查询MCP server的网站也很多。

🔗 **X pip - Shell连接中心和远程文件管理器**
- 是管理Linux服务器终端工具的替代选择，设计思路大而全。
- 分为Connection HUB（管理连接）、文件浏览器（远程文件访问）、终端启动器（快速启动终端会话）三个功能模块。
- 支持多种远程连接类型，可管理脚本和密码，跨平台，安装方便，适合不喜欢折腾的人。

💹 **多智能体量化交易项目**
- 概念性验证项目，探索人工智能在角色交易中的应用，多智能体结构，模拟多种投资策略的agent进行股票分析和策略交易。
- 涉及的agent有本杰明格雷厄姆、查理芒格、沃伦巴菲特等。
- 使用方法：下载源码，安装依赖运行，支持多种大模型，但数据使用的API要钱且无A股数据，用于教育，不适用于实际交易和投资。

🎮 **其他小分享**
- 分享红警二网页版，打开网页可安装游戏并开玩，速度流畅且支持联机。
- 博主下载了data science资料，想要的可在评论区留言获取链接 。

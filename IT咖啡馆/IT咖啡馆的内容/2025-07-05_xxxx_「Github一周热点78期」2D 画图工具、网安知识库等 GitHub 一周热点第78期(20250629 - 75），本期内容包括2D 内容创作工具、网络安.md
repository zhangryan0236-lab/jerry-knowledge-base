## AI 摘要

📱 **2D内容创作工具**
- Graphite是基于Rust开发的2D内容创作工具
- 支持平面设计、数字艺术和交互动态图
- 提供非破坏性编辑，所有操作可编辑
- 采用节点式编辑环境，类似Blender
- 网页版阿尔法版本已上线，桌面版预计2025年发布

🔐 **网络安全知识库**
- 提供外部应用安全的payload和绕过方法
- 收录200多种攻击payload，包括SQL注入和OS漏洞
- 包含漏洞描述、利用方法、工具和参考信息
- 提供Root Me挑战链接，是红队知识库的优秀资源

🌐 **JavaScript 3D引擎**
- Three.js是轻量级跨浏览器JavaScript 3D引擎
- 基于WebGL实现，适合创建3D动画和可视化应用
- 开源社区活跃，提供丰富的教程和素材
- AI技术降低了Three.js的入门门槛

🖥️ **命令行文本编辑器**
- Switch.js是微软发布的命令行文本编辑器
- 向经典MS-DOS编辑器致敬，现代化界面
- 体积仅230KB，支持查找、替换、自动换行等功能
- 将作为Windows 11的默认命令行编辑器

📚 **个人图书馆管理**
- Lo是自托管应用程序，用于管理个人书籍收藏
- 支持多用户和阅读进度管理
- 自动获取书籍详细信息，支持Docker部署
- 技术栈为Spring Boot和Angular

📄 **资料分享**
- 微软应用市场推出中国市场PC应用开发者白皮书
- 计算机图形学资料《Computer Graphics from CS》

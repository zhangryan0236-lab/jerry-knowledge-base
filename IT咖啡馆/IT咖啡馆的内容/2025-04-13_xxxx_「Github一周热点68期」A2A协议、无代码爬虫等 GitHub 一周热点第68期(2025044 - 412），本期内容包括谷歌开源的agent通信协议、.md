## AI 摘要

📜 **A to a通信协议**
- 谷歌开源的Agent to Agent协议，旨在打破Agent之间的壁垒，帮助企业解决采用Agent时的最大挑战，让不同框架和应用商构建的Agent协同工作。
- 执行流程包括发现、启动、加工、交互、完成。
- 设计核心概念有代理卡、A to a server、A to client、任务、消息、弓箭流逝、传输、推送通知。
- 因谷歌推动及AIA市场火热，发布后热度高，有强烈企业级气息。

🧰 **麦克On（无代码外部数据抓取工具）**
- 对不懂代码或不愿写爬虫的人友好，先训练机器人，设置抓取内容和规则，能抓取列表、文本、截图。
- 配置通过可视化完成，可抓取电商价格、新闻内容、竞品分析等。
- 支持BP，可处理分页和滚动，支持特定时间运行机器人，能将网站转化为API和Excel表格。
- 有云托管版本需填申请表，建议在Linux环境本地部署，可选择docker或源码启动。

📁 **Al list（支持多存储的文件列表程序）**
- 可将本地存储、阿里云盘、百度网盘等多种网盘接入一个网页。
- 可结合播放器实现看片自由，组合纳斯等工具实现更多玩法。
- 兴起与小雅list有关，上周曾出现商酷问题，项目首页和组织现已恢复正常。

💻 **科ser自动续杯工具**
- 是AI编程首选科ser的自动化配置工具，可自动注册完成认证，重置科ER配置。
- 自动化流程，支持多语言、多平台。

📚 **MCP开发SDK（fast m cp）**
- 最初是独立开源项目，现成为MCP官方Python SDK，品质获官方认可。
- 快速入门：引入fast m cp，增加tool resource等内容，可通过命令行工具快速安装和调试。
- 项目在发展VR版本，扩充如MCP client快速开发等功能。

📖 **资料分享**
- data well出品的面向开发者的LLM入门教程。
- 阿里发布的AI应用开发新范式，针对很多MCP分析。

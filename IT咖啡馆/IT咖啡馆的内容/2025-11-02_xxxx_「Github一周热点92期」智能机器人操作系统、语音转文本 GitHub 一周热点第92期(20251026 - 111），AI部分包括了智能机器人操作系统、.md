## AI 摘要

🤖 **AI部分**
- OM1：由Open Mine开源的模块化AI运行时环境，旨在成为智能机器人操作系统，不依赖硬件平台，支持多种数据输入，能控制机器人行动，构建视觉到动作的闭环系统。采用模块化设计，以Python实现核心，支持插件化扩展和多种硬件接口，提供外部调试界面，支持配置多种大模型，有快速入门和示例。
- Handy：开源免费可扩展的语音转文本桌面应用，可完全离线使用。基于Tory和React构建，后端本地执行语音识别保护隐私。适用于多平台，在release下载安装包，首次运行下载模型，可设置快捷键，默认模型不支持中文，换whisper模型可实现中文转换，能查看识别历史记录。
- SOM100：开源的3D打印可组装机器人机械臂系统，降低进入机械臂与多模态智能交互系统的成本。最新款是SOM101，硬件包含双万结构等，3D打印组件可自制或购买，安装说明详细且有配套视频，适合教学、科研等多种场景。

🧰 **工具部分**
- Black Hole：专为Mac平台设计的虚拟音频工具，可在应用间传递音频输出作为另一应用的输入，能解决Mac默认录屏无法录制系统内部声音的问题，适用于音频录制等多种专业场景。
- Blind Watermark：可在图像中嵌入盲水印，提取时无需原图，是Python库，安装后用简单命令即可实现加水印功能，适用于图像权限保护等场景。
- VimTerminal：将传统终端功能与图形化相结合的终端工具，可在多平台使用。集成文件预览、网页浏览、人工智能辅助等功能，有灵活拖放界面等特性，是终端、图形、AI融合平台，计划支持更多AI功能。

📖 **资料分享**
- 企业级的AIGC的价值及应用报告：随着AIGC浪潮，AI技术正从单纯内容生成向更深层次智能体演进。

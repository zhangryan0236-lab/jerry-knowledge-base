## AI 摘要

💻 **K transformers**
- 由清华大学KV Cache团队联合曲靖科技发布，为大模型在受资源限制的本地部署优化。
- 打破部署困境，只需24G显存就能本地运行DeepSeek R1或V3的671B满血版，预处理速度达286token每秒，推理生成速度达14token每秒，性能是拉玛cpp的27倍以上。
- 网友用3090显卡和200G内存实测，借助微调工具优化后，推理速度达9token每秒。
- 提出CPU稀疏注意力框架，降低最低CPU内存要求，使本地运行128K甚至1M token的上下文成为可能。
- 自带实用功能，集成简单web chat，支持提供API。

⚙️ **Isloss**
- 开源大模型微调工具，通过重新设计和手写GPU内核，深度优化计算密集型数学步骤。
- 不换硬件，让模型训练速度最多提高30倍，最高降低90%内存占用。
- 提供丰富适合初学者的notebook，添加数据集后点击运行全部可获速度快两倍的模型微调。
- 可导出到GGUF、欧拉马、VLLM或上传到哈根费斯。
- 最新更新引入推理功能，7B显存可重现DeepSeek R1顿悟时刻，还能将lama、mistro等模型转换为推理模型。

📊 **Dataformulator**
- 微软开源的AI数据可视化工具，利用人工智能创建丰富可视化效果。
- 结合用户UI界面与自然语言输入，以交互形式为用户设计图表，将数据转换交给AI处理。
- 兼具零代码、人工智能灵活迭代和开源免费特性。
- 可通过pip快速安装部署，也可用GitHub的Code Space或源码启动。
- 使用时需提供大模型密钥，选择图表类型拖放数据字段进行视觉编码，还可通过自然语言描述扩展内容。

🔌 **Hopscoss**
- 开源免费快速的API工具，原名postwoman。
- 提供直观界面和丰富功能，支持各种http请求方法，有可视化请求构建器和响应查看器。
- 提供身份支持、环境变量、历史记录导入导出等功能，还有代码生成器。
- 支持跨平台，有在线版本、官方下载链接的安装包和自托管版本。

🎨 **Lucy's**
- 开源图标库，提供一千多个svg文件，用于数字和非数字项目显示图标和符号。
- 提供多个官方软件包，方便开发人员和设计人员整合到项目中。
- 图标颜值高、风格统一，颜色、尺寸等可自定义。
- 通过npm包分发，支持ES模块、tree shaking，占用体积小，支持主流前端框架。
- 提供figma插件，网站可搜索图标。

## AI 摘要

🎯 **欧米平台**
- 全开源平台，旨在解决大模型各阶段复杂问题，提供构建端到端基础模型的全面方案
- 与超13个研究型大学学者建立合作
- 可通过pip安装，用CLI命令训练、评估和推理模型，项目提供详细notebook

📐 **DeepSeek多模态框架**
- 新年之前发布jas PRO和jas flow两款多模态框架，统一多模式理解和生产
- jas PRO是先前版本的高级版，有更优训练策略、扩展训练数据和更大模型大小
- 生成图片质量有提升，但与专业模型有差距，具备图像识别、地标识别、文字识别等多种能力
- Mac使用有问题，默认代码是库达的，输出尺寸384×384貌似不可修改

💡 **千问2.5VR**
- 阿里云春节前后发布，是千问模型家族旗舰视觉语言模型
- 相比千问2VR有巨大飞跃，能更好识别图片内容、支持agent、理解长视频、有视觉定位能力、优化结构输出
- 旗舰模型72B在多任务和基准测试表现出色，7B模型在多任务中超过GBT4MINI水平

🧰 **Browse user**
- 用Python编写的开源库，让AI控制浏览器完成任务
- 结合自然语言处理、playwright和大语言模型，使用效果超open a的operator
- 支持多标签页管理、视觉识别与内容提取、多种大模型，有自我纠正机制
- 先pip安装，再安装playwright并配置大模型API密钥即可使用，有上层项目Web UI提供更方便界面

📊 **Meta base**
- 开源商业BI工具，助用户从数据库提取数据并转化为图表和仪表盘
- 无需编写circle，非技术人员可简单操作创建报告和可视化分析
- 安装简单，有图形化查询构建器，提供多种可视化表格类型
- 可通过docker或Java启动，启动后在3000端口使用服务

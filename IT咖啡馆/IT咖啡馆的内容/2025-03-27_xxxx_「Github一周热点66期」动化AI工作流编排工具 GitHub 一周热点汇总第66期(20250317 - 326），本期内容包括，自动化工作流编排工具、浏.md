## AI 摘要

🧰 **N8N - 自动化工作流工具**
- 被称为自动化领域的瑞士军刀，目标是通过可视化操作连接不同应用和服务，自动完成重复性任务
- 拥有400多个集成和900多个模板，支持原生AI功能，开源可控，可自托管部署
- 提出公平代码模式，鼓励企业向开源贡献者提供补偿
- 可通过NPX启动或docker部署，适用于AI、数据分析、企业管理等多方面
- 与其他工具对比：N8N更关注自动化流程，让AI融合更多业务数据

📁 **FilePizza - 浏览器文件分享工具**
- 基于WebRTC实现点对点文件传输，无需上传到中间服务器，速度快、私密性和安全性好
- 要求上传者保持浏览器窗口打开直到传输完成，支持多人下载
- 通信使用公钥自动加密，可选择添加密码增加安全性，可在线使用或自行部署

📱 **WeChat Real Friends - 微信好友检测工具**
- 使用简单，安装后打开扫码登录即可
- 能快速检测微信单向好友，并自动打标签，可批量处理，理论上支持检测上万好友
- 使用微信iPad协议，使用需谨慎，可能被微信封禁

🎯 **Glass - 自托管信息仪表盘**
- 独创折叠式信息流设计，可整合超20种数据流到统一界面，实现零切换信息管理
- 可添加RSS信息源、天气、股市等多种信息
- 通过docker快速启动，镜像小巧（约21兆），部署灵活，可用于家庭服务器

🤖 **The Robot - 开源低成本AI机器人解决方案**
- 由Hugging Face开源，旨在降低机器人技术门槛，让开发者轻松构建和训练AI机器人
- 示例成果SO100每支手臂仅需110美元，配套教程详细
- 有升级版Le Vickki，有详细介绍和教程，在业内较受关注

📚 **其他分享**

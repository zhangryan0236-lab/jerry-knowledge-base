## AI 摘要

📈 **热点汇总概述**
- 本期汇总时间为2025/03/02 - 3/08，涵盖Manus开源实现、AI Agent工具集、C语言2D UI布局库、高性能游戏数据库和红警系列游戏等内容。

🤖 **OpenMinus开源项目**
- 是Minus的开源实现，基于智能体的工作流自动框架，采用分层架构设计。
- 支持复杂任务的规划、执行和验证，通过可扩展工具集和提示模板库实现灵活任务处理。
- 目前处于概念阶段，代码量不多，在agent里可了解其思路，不同类型agent负责不同工作。
- 项目团队专业搞agent，还有知名项目Mate GBT 。

🧰 **Composer工具集**
- 适用于AI Agent的生产就绪工具集，帮助AI快速实现工具调用，类似多合一数据线。
- 支持超250种工具，如Github、Notion等，还支持多种框架。
- 支持Python和JavaScript两种开发语言，以Python为例，通过pip安装包及OpenAI插件包，参考官网例子可上手。
- 因升级版本提供对MCP的支持而爆火，MCP是Cloud推出的开放协议，Composer提供了MCP的server 。

🖼️ **Clay布局库**
- 用C语言开发的高性能2D UI布局库，能实现微秒级布局性能。
- 通过层次结构关联UI组件，支持类似Flex Box的布局模型，适用于复杂和响应式布局。
- 只做布局输出，不做渲染，与渲染器无关，可在任何3D引擎中渲染合成。
- 支持WebAssembly，语言结构类似React嵌套声明语法，无平台依赖，有丰富参考文档和介绍视频。

🎮 **Space Time DB数据库**
- 高性能多人游戏数据库，本质是管状数据库，可将应用程序逻辑通过模块化存储过程上传到数据库。
- 开发团队是游戏工作室，为解决传统游戏开发困难而开发，正在做一款MMO RPG游戏。
- 是嵌入式数据库，连接代码和数据库，节省网络传输消耗，性能达Post Graph Circle的15倍以上。
- 推出了云服务。

🎯 **EA游戏合集**
- EA将命令与征服系列四款经典游戏开源，采用GPL开源许可协议，包括泰伯利亚的黎明、红色警戒、叛逆者和将军的绝命时刻。
- 此前开源过该系列但只放出部分DLL，此次是整个工程文件。
- 红警虽老，但开源后可能激起大量二次开发，产生衍生作品。

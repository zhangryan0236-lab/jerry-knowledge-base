## AI 摘要

🔒 **AI安全工具Promptful**
- 用于评估和红队测试大模型应用的工具，帮助交付安全可靠的AI应用
- 核心功能：自动评估提示词、模型对比、红队测试、漏洞扫描及CI/CD自动化检测
- 2026年3月9日被OpenAI收购，整合进企业级智能体协作平台OpenAI Frontier
- 安装方式：通过npm安装，支持CLI或GUI使用，已有数十万人使用

👥 **AI代理事务所**
- 非具体工具，而是AI Agent人设集合，每个Agent有独特专业领域、性格及工作流程
- 工程部包含前端开发、后端架构、移动开发等20+角色，提供完整定义文档（身份定位、专业能力等）
- 推荐配合Cloud Code使用，支持复制isms文件夹到对应目录，也支持Coser、Windsof等工具（提供转换脚本）

🛠️ **OpenCloud技能库**
- 从Cloud Hub的13000+社区Skill中筛选出5400+高质量Skill（过滤垃圾账号、重复内容、加密币恶意插件）
- 按类别清晰分类：外部服务连接、开发工具、生产力工具、AI相关等
- 安装建议：使用`opencloud install`或直接提供Skill链接，推荐安装SkillWhite技能进行安全审查

🔍 **Cloud Code插件CloudHud**
- 显示Cloud Code当前状态：上下文使用情况、活跃工具、运行中Agent、代办事项进度
- 安装步骤：先安装Marketplace，执行插件安装，配置状态后重启Cloud Code
- 基于Cloud Code原生状态线API，无需单独窗口，支持任意终端

📊 **上下文数据库OpenViking**
- 字节开源的AI Agent基础设施，解决上下文碎片化、检索效果差等问题
- 核心功能：统一管理Agent记忆资源与技能，提供层级化加载与访问路径
- 配合OpenCloud使用时，原生记忆效果提升43%，输入Token成本降低91%
- 支持多种模型，需满足前置环境要求

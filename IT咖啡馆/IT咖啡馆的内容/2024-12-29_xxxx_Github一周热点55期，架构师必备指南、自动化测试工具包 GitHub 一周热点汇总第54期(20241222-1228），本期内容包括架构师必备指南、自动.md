📖 **架构师必备指南项目**
- 收集互联网上系统设计原则资源，帮助学习构建可扩展系统
- 目标针对架构师人群，内容与架构师考试思路类似，有面试题及详细解答
- 附带需掌握的关联知识点，有flash功能巩固知识，还有关联项目用于编码挑战

🧰 **Cyna base自动化测试工具包**
- 基于web的自动化测试专业工具包，用于测试网站绕过人机验证等
- 基于slim框架的Python库，简化自动化脚本编写和调用，与py test框架深度集成
- 提供脚本录制、运行慢放等多种脚本模式，example文件夹有大量示例脚本
- 可借助PY生成测试dashboard，有GUI（sium based commander）直观调用测试

🖌️ **KL draw无限画布白板**
- 开源免费的无限画布白板，可在线实时协作
- 目标是提供简单易上手绘画工具，即使无专业绘画经验也能轻松上手
- 背后使用TL draw开源项目，提供团队协作支持
- 可本地运行（克隆代码执行命令），也可集成到react项目（通过NPM安装并简单引用）
- 有借助open AI将UI图直接生成产品的开源项目（make real）

🧪 **AI驱动的自然语言端到端测试框架**
- 基于playwright构建，利用自然语言编写测试，让AI处理和执行
- 使用a cloud API执行人工智能驱动的测试，与github无缝集成
- 安装简单，参考项目代码示例完成配置，在测试目录写测试用例
- 可使用function call或hook扩展测试能力

🚫 **U block广告拦截器**
- 适用于Chrome或firefox的多用途拦截器，有良好CPU和内存效能
- 默认使用常见信息拦截列表，阻止广告追踪器等内容弹出
- 支持使用easy list过滤语法扩展自定义拦截规则和过滤器
- 针对不同浏览器提供对应插件，有基本模式（适合追求简单用户）和高级模式（适合需自定义用户）

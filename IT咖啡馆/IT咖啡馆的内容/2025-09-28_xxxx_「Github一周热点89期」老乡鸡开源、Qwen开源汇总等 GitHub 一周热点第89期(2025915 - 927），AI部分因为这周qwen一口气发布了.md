## AI 摘要

🌟 **云栖大会AI模型发布**
- 千问在云栖大会上发布多个模型，涵盖语言、视觉、语音、多模态代码等多个方面。
- 千问三next：下一代架构模型，通过创新架构用3B激活参数达到235B稠密模型性能，训练成本降90%，推理效率提升。
- 千问三vl视觉模型：从实图进化到推理与执行，能操作电脑手机界面，生成html和css代码。
- 千问三omini全模态模型：能同时处理文本、图像、音频、视频，在多项测评中表现出色，可实时语音对话、自定义人格。
- 千问三coder专业代码模型：全面升级，速度更快、代码更安全，能部署完整项目。
- 千问三tts语音模型，还有整合模型百灵。
- 万2.5：在图生视频等方面更强大，实现音画同步电影级视频生成，时长和画质提升。
- 千问三max：非开源，是千问家族最强模型，对标gpt5和cloud4alps，万亿总参数，支持百万透根上下文。

🔧 **AI开发框架与工具**
- copelit kit：将ai copelit添加到应用程序的框架，可连接app逻辑状态和上下文到ai agent，为app提供动画和交互。
- asgen scope：面向开发者的代码的asg开发框架，在github上获超12k star，升级到v1.0版本，架构分三层。

🎯 **其他实用工具**
- 想像老乡鸡一样去做饭：基于老乡鸡菜品溯源报告整理编辑的项目。
- tl照：开源免费无线画布白板，可在线实时协作，功能全面，提供复杂场景事例和构建上下文的content md及脚本。
- arclinix：经简单命令可变身为现代化开发神器，自动安装和配置相关工具和主题。

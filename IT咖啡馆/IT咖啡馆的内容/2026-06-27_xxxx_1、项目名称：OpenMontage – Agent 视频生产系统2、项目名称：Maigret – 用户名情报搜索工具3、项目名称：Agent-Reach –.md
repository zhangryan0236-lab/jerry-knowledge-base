## AI 摘要

🎬 **Open Mantage（开源智能体视频制作系统）**
- 全球首个开源智能体视频制作系统，将AI转化为完整视频制作工作室
- 支持自然语言输入需求（如“60秒神经网络科普动画”），自动完成选题研究、脚本生成、素材生成、配音字幕音乐剪辑及合成
- 内置12条完整制作流水线（动画解说、纪录片剪辑、虚拟人物播报等），不同流水线采用不同模型和技术
- 包含52个制作工具和500+技能，支持免费资源，无需额外API即可完成基础视频制作
- 本质为视频生产工程框架，需Python、Node.js等环境，配置OpenAI/Runway/Eleven Labs等API可提升效果
- 支持复刻爆款视频：分析目标视频的字幕、节奏、场景、关键帧和风格，生成新制作方案

🔍 **用户名情报搜索工具**
- 输入用户名可在3000+网站查找对应公开账号并整理成报告
- 无需配置API，Python 3.10+环境下通过`pip install`安装，执行`megalay 用户名`启动
- 默认检查流量最高的500个网站，支持参数扩展扫描范围
- 提取公开页面和接口信息，提供Web界面浏览结果，可导出HTML/PDF/XML格式
- 新增AI分析模式，将原始结果整理为调查摘要
- 暂不支持抖音、小红书、B站等中国大陆常用平台，支持豆瓣、贴吧、知乎，可自行扩展

🌐 **A震的Rich（AI联网冲浪工具）**
- 解决AI联网难题（如处理HTML、平台登录限制等），为AI提供稳定联网能力
- 作为能力层，选择并配置当前最稳定的上游工具（如网页读取用GenAI Reader、GitHub用官方CLI、YouTube用yt-dlp、小红书用OpenCRI等）
- 提供工具配置引导（如配置Cookie、装插件），无需记忆各平台命令
- 需注意风险：配置Cookie的平台（如推特、小红书）建议用非主账号，存在封号风险

💻 **Codebase Memory MCP（代码库记忆引擎）**
- 面向AI编程Agent的代码库记忆和智能引擎，将代码仓库索引为本地知识图谱
- 解决大型项目中Agent反复读取文件导致的Token消耗大、易漏调用关系问题
- 支持函数、类、调用链、HTTP路由、跨服务关系等结构化分析，形成知识图谱节点和边
- 性能优异：普通仓库毫秒级索引，2800万行代码、7.5万个文件的大型仓库3分钟内完成索引
- 用Tree-sitter支持518种语言，Hyper LSP增强类型解析，覆盖Python、TypeScript、Go等常用语言
- 本地处理，单静态二进制文件即可运行，隐私友好，底层基于C编写，性能优于TypeScript

🎥 **OpenCat（开源视频剪辑工具）**
- 定位为CapCut（剪映国际版）的开源替代，支持Web、桌面和移动端
- 新版本重点方向：Editor API、插件优先架构、MCP Server、无头模式、编辑器内Script Type
- 目标是让AI参与视频剪辑（传统工具以人工交互为主）
- 开源剪辑工具面临专业工具成熟、用户习惯难改的挑战，AI可能带来新机会，暂无法替代达芬奇、PR或剪映

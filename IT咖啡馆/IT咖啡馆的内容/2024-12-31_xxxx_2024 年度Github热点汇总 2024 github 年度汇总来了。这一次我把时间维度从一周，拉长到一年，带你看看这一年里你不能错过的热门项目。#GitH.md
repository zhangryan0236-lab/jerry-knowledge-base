## AI 摘要

🧠 **AI 领域项目**
- **Llama**：自 2023 年发布后成为众多开源模型对标对象，推动了自研大模型发展。2024 年 4 月 Meta 发布 Llama 3 两种尺寸模型；7 月发布优化的 3.1 版本并扩充 405B 版本；9 月发布的 3.2 版本支持视觉推理并优化中小版本性能。
- **Olama**：降低了用户本地部署和使用大模型的门槛，无需深入了解底层技术，支持跨平台，提供 Rise API 兼容 OpenAI 接口和多语言 SDK。
- **LoveChat**：从开源聊天机器人框架发展为个性化定制 AI 助手，功能扩展到多模态、支持私人 Agent、语音、插件扩展、RAG 等，还在扩充生态。
- **GPT Service**：声音克隆工具，一分钟语音数据可训练 TTS 模型，优势有零样本 TTS、跨语言推理等，上手难度和资源需求低。
- **Compi UI**：强大且模块化的 AIGC 的 GUI，支持多种生成模型和视频生成模型，可通过模块化拼装构建复杂工作流。
- **Flex**：黑森林工作室推出的生图模型，是目前生成图片质量最高的开源模型，但模型大，吃显存，有三个版本，Pro 版商业不开源。
- **提示词项目**：与 ChatGPT 一起使用的提示词事例集合，带有出处和说明，有助于构建自己的提示词。
- **LongChain**：大模型应用开发框架，不仅局限于 Python，提供其他语言 SDK，生态不断扩展，发布了人工智能全景报告。
- **千问**：2024 年强势崛起，6 月阿里发布千问 2 系列模型，在多方面表现出色，9 月发布千问 2.5 能力增强，全球下载量突破四千万，衍生模型超 7.8 万个。

🛠️ **其他技术项目**
- **Build your own x**：教用户动手实现热门技术，收集众多教程系列，涵盖编程语言、数据库等多种软件和工具构建。
- **Hello, iogo**：通过动画图解讲解算法和数据结构，配套可运行源码程序，有互动社区，支持多种学习方式和编程语言。
- **In**：高性能多人代码编辑器，由奥特曼创建者开发，用 Rust 语言，发布后发展迅速，功能不断增加。
- **Windows in Docker**：可在 Docker 里运行 Windows，支持 win7 到 win11 系统，可设置参数启动不同版本。
- **微软 PowerToys**：为高级用户设计的免费系统增强工具集，包含多种实用功能，可提升 Windows 操作系统效率。
- **Flutter**：Google 开发的开源 UI 工具包，通过单一代码库构建高性能跨平台应用程序，有自己的渲染引擎，社区和组件生态丰富。
- **Home Assistant**：基于 Python3 的开源家庭自动化平台，可跟踪和控制家庭设备实现自动化，数据本地存储，支持多平台和众多设备。
- **Gatsby**：基于 React 框架构建高性能网站的框架，拥有全球化和多元化社区，基于 GAM stack 概念开发。
- **Prism**：开源 ORM 工具，简化数据库访问，提供类型安全查询，强调数据库优先，使用直观。
- **Rest Desk**：用 Rest 写的远程桌面，支持多平台连接，曾因国内诈骗问题屏蔽国内 IP，需自行部署中继服务器才可使用。

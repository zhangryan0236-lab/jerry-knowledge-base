# oMel · 知识维基

> 基于 Karpathy LLM Wiki 模式，将 52 期读书分享视频（2025.03—2026.07）整合为可导航的知识系统。
>
> oMel 是一个**读书分享频道**，每期精讲一本书的核心思想并提炼可执行的行动指南。跨越心理学、认知科学、商业思维、哲学、人际沟通等领域，以"读完就能用"为核心理念。

---

## 核心框架：输入 → 内化 → 输出

```
        ┌──────────────────────────┐
        │       输  入  层         │
        │   52 本精选书籍          │
        │   (心理学·认知·商业·哲学) │
        └───────────┬──────────────┘
                    │
        ┌───────────▼──────────────┐
        │       内  化  层         │
        │   四大支柱：              │
        │   心智管理·学习科学       │
        │   习惯系统·财富思维       │
        └───────────┬──────────────┘
                    │
        ┌───────────▼──────────────┐
        │       输  出  层         │
        │   创造表达·人际沟通       │
        │   生命哲学·自我认知       │
        └──────────────────────────┘
```

**oMel 的独特价值**：
- 一本书 = 一个视频 = 提炼出 3-5 个可执行的要点
- 不需要读原书就能获得核心思想（但推荐去读）
- 强调"行动指南"而非"知识囤积"

## 与另外两个频道的互补

| 维度 | 学渣守护者 | 忽然知己 | oMel |
|------|-----------|----------|------|
| **形式** | 原创经验分享 | 原创思考+哲学 | **读书精华提炼** |
| **深度** | 实战技法 | 哲学原理 | **认知模型** |
| **来源** | 个人教学经验 | 学术+哲学训练 | **全球精选好书** |
| **适合** | 需要信心和启动 | 需要理解本质 | **需要认知武器库** |

> 💡 **三者互补使用**：学渣守护者给你"我能行" → 忽然知己给你"为什么能行" → oMel 给你"全球最聪明的人是怎么做的"。
